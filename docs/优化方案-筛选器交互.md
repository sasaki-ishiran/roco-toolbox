# 筛选器交互整体优化方案（2026-10-05，待用户拍板后实施）

> 用户要求：性格 / 声音 / 体型作为**独立折叠标签**，点开展开详情、同时只展开一个（手风琴互斥）；
> 整体排布紧密；解决「选完想收起要滚回顶部」；**所有页面**的筛选相关统一优化。
> 本方案先审批，通过后再改代码。

## 一、统一交互规范（手风琴式筛选条）

1. **手风琴互斥**：每个筛选维度是一个折叠头（标题行），点击展开该维度、自动收起其它维度；同一时刻只开一个。
2. **选项即选即收起**：在展开的维度里点选某个选项后，**该维度自动收起**（回到「标题行 + 已选摘要」），
   无需滚回顶部就能继续开下一个维度。标题行始终显示当前已选（如「声音：+100、-100」）。
3. **筛选条置顶常驻（sticky）**：处于页面上部的筛选条 sticky，页面滚动了也能直接在当前位置收起/改选。
4. **排布紧凑**：选项 chip 行高 26~28px、间距 1.5，一个维度一行标题，纵向总高显著收窄。
5. **重置**：筛选条右上角保留「重置」按钮（一键清空本页筛选）。
6. 搜索框（我的精灵 / 特殊精灵的名称搜索）保留，放在筛选条最上方一行。

**适用页面**（统一改造）：
- 我的精灵 · 全部（性别/体型/声音/稀有度/蛋组/性格 六组 + 搜索 + 重置）
- 我的精灵 · 种公（档位 / 性格）
- 母本视角 · 待补齐母本（**声音 / 体型** 达标条件，同手风琴）
- 性别比例特殊精灵（声音 / 体型 / 性格 + 名称搜索）
- 覆盖度页自有过滤条（蛋组/档位多选）保持 chip 形式但同样**紧凑化**；页内「推荐/自选性格」开关不动

## 二、母本达标条件修复（本轮确认的 bug）

- **bug**：只选「大块头」（声音全不选）或只选「100db」（体型全不选）时，显示「全部没收集」。
  **根因**：某维度一个选项都没选时，该维度匹配恒为 false，把整条链都排除。
- **修法**：**某维度一个都不选 = 该维度不限**（不设门槛）。维度内多选 = OR，维度间 = AND
  （即「有母本同时命中所选体型与所选声音」才算已达标）。
- **声音选项随模式联动**（用户拍板）：
  - **追满分**：只显示 `+100` / `-100`（默认两个都选 = 满分口径）
  - **追双牌**：只显示 `婉转声` / `粗嗓门`（默认两个都选 = 任意声音牌）
  - 切换模式时选项与默认选中同步切换。

## 2. 形式化：布局 → 命中 → 期望产出

### 2.1 布局与几何
- 小窝 `i` 有位置 `p_i`（2×2 左上角整数坐标）。中心距：现码用**曼哈顿** `D₁(i,j)=|Δx|+|Δy|`；蛋神助手用**欧氏** `D₂(i,j)=√(Δx²+Δy²)`（单位＝窝宽）。
- 重叠：`|Δx|<2 且 |Δy|<2`（切比雪夫 < 2）。
- **可配对（边）**：`D(i,j) ≤ 阈值` **且** `(pets_i, pets_j) 共蛋组` **且** `性别相反`。
- 记「可配对图」`G=(V,E)`；**连通组**＝`G` 的连通分量（簇 = 设计上刻意分离的连通组）。

> 阈值换算【假设】：2×2 窝的**中心偏移 = 左上角坐标差**，故 `D₁ = |Δx|+|Δy|`（格）。换算到「窝宽」（1 窝宽 = 2 格）：`D₂(窝) = √(Δx²+Δy²)/2`。于是
> - 现码 `D₁≤5` ⟺ 曼哈顿 `≤2.5 窝宽`；
> - 蛋神 `D₂≤2.125 窝宽` ⟺ `√(Δx²+Δy²) ≤ 4.25` 格。
> 二者**量级相近，但 L1≠L2**：`D₁≤5` 允许 (3,2)、(5,0) 这类「斜长 + 细长」配对，`D₂≤2.125` 不允许。**结论：L1 口径比 L2 宽松，会多出不少边。**

> **几何发现（重要）**【假设·可验证】：在 **欧氏 ≤2.125 窝宽 + 不可重叠** 下，**不存在 3 个两两可连的小窝（无 3-团）**。
> 证明直觉：可连的一对必须 `|Δx|≥2`（否则重叠），于是 `|Δy| ≤ √(2.125²−2²)=0.72 格`，即两窝几乎「正东西相距 2 格」。第 3 窝要同时离这两窝 ≤2.125，又离它们 Chebyshev ≥2，无解。
> **推论**：蛋神口径下，绿窝要挂 2 条线只能是 **「V 形」**（绿窝为铰点，两个配对方互不相连）；现码曼哈顿≤5 下则可构成 **3-团**（`(0,0),(2,0),(4,0)` 两两 ≤4）。这直接影响 §3 的分组判定。

### 2.2 时间与判定（两种模型）
设单条边的事件率 = `λ`（默认 `λ₀=1/3.6 /h`）。`active(i)` 表示窝 i「可孵蛋」（无未取的蛋、不在 CD）。

**(M1) 多路径模型（edge-based）**
- 每条边 `e=(f_e,m_e)` 独立按 `λ_e` 触发；触发即在母窝 `m_e` 落一颗蛋。
- 母窝 `m` 的产蛋事件率：`ρ_m = Σ_{e∋m} λ_e`（**与度数成正比**）。
- 绿窝命中率（进 CD 速率）：`ρ_A = Σ_{e∋A} λ_e = d_A · λ`。

**(M2) 分组模型（component-based）**
- 每个连通组 `C` 只有**一次**判定，触发率 `λ_C = λ`（与组内边数无关）。
- 触发后按母本权重 `w_m` 选一只母本落蛋：`P(落到 m) = w_m / W_C`，`W_C = Σ_{m'∈C} w_{m'}`。
- 母窝 `m` 产蛋事件率：`ρ_m = λ · w_m / W_C`（**随组变大而变稀**）。

### 2.3 CD、占位、退出计数
- 普通窝：`active≡true`（只要没被未取的蛋占住）→ 事件率恒为 `ρ_m`。
- 绿窝：**更新过程（renewal）**。设其 active 期命中率 `ρ_A`，则
  - 期望周期 `C_A = 12h + 1/ρ_A`（12h CD + active 期到下一次命中）；
  - 稳态产蛋率 `= 1 / C_A`。
- 蛋未取走：母窝 `active=false` → 从 `W_C` / 边集中移除，份额**重新分配**（M2）或该母窝所有边静默（M1）。

### 2.4 一颗蛋的「有用性」
一颗蛋对缺口 `j=(蛋组 g, 性格 n, 档位)` 有用的概率：
```
P_useful(e, j) = 1[母方 ∈ g] · 1[遗传性格 = n 达成] · 0.5(性别=公)
              = r_tier · 0.5 ,    r_tier ∈ {1, 0.6, 0.3}   （当母方覆盖 g 时）
```
其中 `1[母方∈g]` 由选母决定（**物种随母方**，要补 g 组种公则母方必须∈g）→ 满足时为 1。
> 于是单个指定的「目标配对」的**有用种公产出率**：`Λ_p = ρ_m · r_tier · 0.5`。

## 3. 两种模型对「绿窝连线多 → 命中率更高」的解释

**用户实测【已确认】**：绿窝连线越多，越容易被判定到产蛋。
- **M1（多路径）**：`ρ_A = d_A·λ` **关于连线数严格递增** → **能解释**。
- **M2（分组）**：`ρ_A = λ·w_A/W_C`，`d_A` 只影响分母 `W_C`（若按度数加权则 `w_A` 也涨，但**同组内加边不提升组的总判定次数**）。极端情形「绿窝 + 2 配对方」在蛋神 V 形下**同属一个连通组** → 整组一次判定 → **加第 2 条线几乎不提高绿窝命中率**，甚至因分母变大而**变稀** → **不能解释**。

> **结论：用户实测支持 M1（多路径）。** M2 更像 NGA 的解包推断；二者可在**不同场景同时成立**（例如「同一连通组内一次判定」是 M2，但「玩家观察到的连线收益」来自 M1 的边计数），需要游戏内实验判定。**本报告两个模型都保留。**

对照现行实现：`nestPlan.ts` 的隔离式设计（「非指定配对必须连不上」）语义**更贴 M2**（怕连通组父亲随机）；而用户「绿窝连线多→命中高」的诉求**更贴 M1**。这是当前设计里一个隐含的**模型混用**，需在第二期统一。

## 4. 具体问题逐条

### 4.1 ① 绿窝挂 1 条线 vs 2 条线

**M1（多路径）下：**
- 进 CD 的期望时间：`E[T_hit] = 1/(d_A·λ)`。
  - `d_A=1`：`1/λ = 3.6h`；`d_A=2`：`1.8h` → **进 CD 速度翻倍（−50%）**。
- 绿窝稳态产蛋率 = `1/(12 + 1/(d_A λ))`：
  - `d=1`：`1/(12+3.6)=15.6h/颗` → `0.0641 /h`（1.54 颗/天）
  - `d=2`：`1/(12+1.8)=13.8h/颗` → `0.0725 /h`（1.74 颗/天）
  - **提升 +13.0%**。
- 若用「每 3.6h 一次判定、成功概率 q」的离散口径，则 `P₁=q`，`P₂=1−(1−q)²=2q−q²`，**比值 `2−q`**：
  | q | P₁ | P₂ | P₂/P₁ |
  |---|---|---|---|
  | 0.1 | 0.10 | 0.19 | 1.90× |
  | 0.3 | 0.30 | 0.51 | 1.70× |
  | 0.5 | 0.50 | 0.75 | 1.50× |

**M2（分组）下：**
- 第 2 条线若与第 1 条**同属一个连通组**（蛋神 V 形下必然如此）→ **命中率几乎不变**（组只判一次），且父亲随机性上升 → **不建议**。
- 第 2 条线若能让绿窝成为**两个独立连通组**的成员 → 命中率才 `≈2×`。但由 §2.1 几何发现，蛋神口径下 V 形必然是**同一组** → **M2 下绿窝挂 2 线基本无收益**。

> **答**：绿窝 1→2 线的价值高度依赖判定模型。**M1**：进 CD 快 1 倍、稳态仅 +13%；**M2**：几乎无收益还可能引入随机父亲。这正是「第 2 条配对**不要求**补新缺口、只买命中率+催化」的直接依据——它只在 **M1** 下划算。

### 4.2 ② 催化效应：绿窝进 CD 仍计数，给普通窝带来多少提速

**机制拆解（【假设】）**：绿窝在连通组里既「计数」（维持 `W_C` / 边数不减少）又「不参与孵蛋」（不占落蛋份额）。它对同组普通**母窝**的提速来自两个通道：
1. **份额再分配**：绿窝不落蛋，其份额转给其余母窝。
2. **计数保留**：若按边数计组判定率，绿窝的边仍计入分母 `W_C`/组规模，避免组判定率下降。

**通道 1（主）**：设组内母窝数 `n`、绿窝占份额 `w_A`，则任一普通母窝的提速因子
```
γ = W_C / (W_C − w_A)
```
- 均匀权重、组内 `n` 只母窝：`γ = n / (n−1)`
  - `n=2`：**2.0×**；`n=3`：**1.5×**；`n=4`：**1.33×**
- 独立性：**只有当组内母窝数 `n≥2` 时催化才存在**。若绿窝所在簇只有「绿窝(母)+1 公」这一对，组内无别的母窝 → **催化率 = 1（无效果）**。

**折算到时间平均**：绿窝只有 CD 期间（12h）才「不落蛋」，占绿窝周期的比例
```
f = 12 / (12 + 1/ρ_A)
```
平均提速 `γ̄ = f·γ + (1−f)·1`。
- 绿窝 2 线（周期 13.8h，`f≈0.87`）：
  - `n=2`：`γ̄ ≈ 0.87·2+0.13 = 1.87` → **+87%**
  - `n=3`：`γ̄ ≈ 0.87·1.5+0.13 = 1.44` → **+44%**
- 绿窝 1 线（周期 15.6h，`f≈0.77`）：`n=2` → `γ̄≈1.77`（+77%）。

> **答**：催化提速 = **绿窝不落蛋时把自身份额让给同组其他母窝**。组内母窝越少，旁落效应越强（2 母窝时期间翻倍）；但**前提是同组里还有别的母窝**，否则为 0。按绿窝 CD 占空比折算，平均 **+40%～+90%**。数值强依赖 A4/A6（份额模型），**敏感度高**。

### 4.3 ③ 隔离式摆位是否最优

**M2（分组）下：隔离式最优。**
- 连通组一次判定 ⇒ 同组多加边**不提升**产出率，只把父亲变随机（增加无关蛋）→ 把非目标配对拉到组外是**严格占优**。
- 代价：绿窝若被隔离成「1 簇」且只有 1 个配对方，则拿不到 M1 的度数增益——但 M2 本就无度数增益，故无损失。

**M1（多路径）下：隔离式对「纯度」最优，但非全局最优。**
- 「非目标边不连」防住无关蛋——正确。
- 但会**牺牲两样**：
  1. **绿窝度数**：若目标配置只给绿窝 1 条线，隔离＝放弃 2× 进 CD 增益；
  2. **催化机会**：把普通母窝隔离到只有 1 个母窝的簇里，催化无对象。
- 因此 M1 下的更优结构是**分层**：**目标配对标** 内部必连；**给绿窝追加「无害边」**（只与目标性格/目标档位精灵相连，不会产无关蛋）以抬高 `d_A`；**把普通母窝与绿窝共置**以吃到催化。

> **答**：**分组模型 → 隔离式既最优又简单，应保留**。**多路径模型 → 隔离式是「纯度最优」，但为了绿窝命中/催化，应允许「绿窝簇内多挂无害边、普通母窝与绿窝共簇」**，即**局部打破隔离**。当前代码（M2 语义 + 隔离式）与用户「绿窝多连线」的 M1 诉求存在张力，需在第二期显式二选一或做加权折中。

## 5. 目标函数与排序准则

### 5.1 「尽快补齐所有缺口」的正式写法

**缺口集** `𝒥`：每个缺口 `j=(蛋组 g, 性格 n, 档位)`，需要 1 只 `大块头 + 性格 n + 公` 且 `∈g` 的种公。
**决策变量** `x=(精灵→窝→位置)`，决定每个缺口 j 的**可用产出率**
```
Λ_j(x) = Σ_{配对 p 覆盖 j} ρ_{m_p}(x) · r_{tier(p)} · 0.5
```
（`p 覆盖 j` ⟺ 母方∈g 且该配对性格目标=n；同一配对经双蛋组母方可同时覆盖多个缺口）。
把每个缺口的「补上时刻」近似为事件率 `Λ_j` 的首次到达，`E[T_j]=1/Λ_j`。

**目标（择一，按可控性）**：
- **最小化最晚补满时间（makespan）**：`min_x max_j 1/Λ_j` ⟺ `max_x min_j Λ_j`（max-min 公平，**最贴合「尽快补齐所有缺口」**）。
- **最大化到 T 时刻的期望补齐数**：`max_x Σ_j (1 − e^{−Λ_j T})`（子模、可用贪心）。
- **线性代理**：`max_x Σ_j w_j·Λ_j`（易解，但会忽略「薄弱缺口」，需配合 `min_j` 约束）。

**需要的参数（落地前提）**：`λ₀`（单边事件率）、共享/竞争规则（M1 vs M2）、母窝份额权重 `w`、催化折算、`r_tier`（已知）、性别 50%（已知）。其中 **`λ₀` 与 M1/M2 是两大未知**。

### 5.2 不依赖精确参数的排序准则（参数拿不到时用）

对每个候选配对 `p`，按**字典序**打分（越靠前越优先）：
1. **补「无替代路线」的缺口**（该缺口只有 `p` 能覆盖）——最高优先，等价于 set cover 里的「必经元素」。
2. **新覆盖缺口数**（`|new(p)|` 多者优先）。
3. **稀有母本/父本保护**：若 `p` 用掉的某只精灵是另一个缺口的**唯一 enabler**，降权。
4. **档位效率** `r_tier`：60% > 30%；绿窝仅在「无 60% 路线」时启用（因 12h CD 让绿窝**吞吐率**低，见 §4.1）。
5. **软奖励 ε·(绿窝度数增益)**：学院第 2 条配对若能把绿窝度数从 1 抬到 2，加一个小 ε（**买命中率+催化**）；同等条件下再按 1~4 比。
   - 用户口径落地：`score(学院第2条) = ε·1[提升 d_A] + 权重(补新缺口)`，ε 小 ⇒ **不要求补新缺口，但补了更好**。

> 该准则只用**已确认**的量（蛋组、性格、档位、是否唯一路线、度数），**不需要 `λ₀`/M1-M2**，可即刻落地为第一期的排序键。

## 6. 算法选择与近似比

### 6.1 问题归类
- 若把「每个配对覆盖一组缺口、每个缺口只需补一次（取并集）」——这是**加权最大覆盖 / 集合覆盖（set cover / max coverage）**。
- 约束「精灵互斥 + 窝位互斥」——叠加**集合打包（set packing）**。
- **关键简化**：
  - **当每个配对恰好覆盖 1 个缺口、且缺口不重叠计数时**，问题退化为**最大权匹配（max-weight matching）** → **匈牙利/Blossom 多项式最优**。→ 匈牙利**只在这个子问题上精确**。
  - 一旦出现「一个配对覆盖多缺口（双蛋组母方）」或「绿窝被两条配对共享」→ 不再是匹配，是 **hypergraph 覆盖** → 匈牙利**不再适用**。

### 6.2 四种手段对比

| 手段 | 适用性 | 近似比/最优性 | 复杂度 | 结论 |
|---|---|---|---|---|
| **贪心** | 最大覆盖 | `1−1/e ≈ 0.632`（子模覆盖）；纯打包 worst-case 更弱 | `O(n log n)` | ✅ 第一期主力 |
| **局部搜索（2-opt 交换/插入）** | 有精灵互斥、非线性速率 | 无保证，小规模近最优 | 每轮 `O(n²)` | ✅ 贪心后的精修 |
| **匈牙利/Blossom** | **仅当**退化为 1:1 匹配（每配对 1 缺口） | **最优** | `O(n³)` | ⚠️ 只作子问题/对照上界 |
| **ILP** | 覆盖 + 速率饱和（`Σ min`）可线性化 | **最优** | 小规模可解 | 🕒 第二期（引入收蛋频率）再用 |

### 6.3 推荐

**第一期（可配建议，不引入收蛋频率）**：
- 目标 = **加权最大覆盖**：`max Σ_j w_j·覆盖(j) + ε·绿窝度数增益`，约束 = 精灵/窝位互斥。
- 算法 = **贪心（按 §5.2 排序键）+ 局部 2-opt 交换**。
- 理由：规模极小（≤11 窝、缺口数十）；覆盖式目标有 `1−1/e` 保证，**实务近最优且完全可解释、可单测**；`ε` 项把用户「不要求但尽量」自然表达。
- **「贪心够不够」的判断：够用**（在覆盖式目标下），前提是补上 2-opt 精修与 §5.2 的字典序键；不需要上 ILP。

**第二期（引入收蛋频率 `ρ`、CD、催化）**：
- 目标含 **速率饱和 `Σ_j min(1, Λ_j·T)`** 与**竞争/催化耦合**（`ρ_m` 依赖同组 `W_C`）→ 非线性。
- 方案：**贪心构造 → 局部搜索（交换/插入）**；若需最优上界，把 `min` **线性化**后用 **ILP** 求解（规模小可接受）。
- 匈牙利仍**只**用于「把 `K` 个缺口指派给 `K` 个独立母窝」的**子问题**（如第二阶段分配），不作全局求解器。

## 7. 与蛋神助手 / 其它口径的对照

| 维度 | 蛋神助手 | 本工具箱目标 |
|---|---|---|
| 几何口径 | 欧氏 **≤2.125 窝宽** | 现码曼哈顿 ≤5（≈2.5 窝宽 L1，更宽松） |
| 目标函数 | **最大化连线数**：12/21 线 · 57.1% | **只产目标蛋** + 尽快补齐缺口（纯度优先） |
| 对「多连线」的态度 | 越多越好（假定 M1） | M1 下有用、M2 下有害 → **不能照抄「连线最大化」** |

- 蛋神的 **57.1% = 达成连线/可行连线**，是**结构指标**，与本模型的 `Λ_j`（有用种公产出率）**不同量纲**。
- 蛋神口径（欧氏、无 3-团）**天然接近隔离式**（配对多为独立两点）——侧面支持「隔离式在 M2 下合理」。但蛋神追求「连线多」与**用户实测 M1 相符**，而与本项目的**纯度目标相悖**：**连线多 = 更多随机父亲机会**（M2）。**故不可直接复用其评分。**

## 8. 假设清单与敏感度

| 编号 | 假设 | 影响的结论 | 敏感度 |
|---|---|---|---|
| A1/A2 | 连续事件率 `λ₀=1/3.6`，3.6h 是单配对平均产蛋间隔 | §4.1 数值 | **高**（若 3.6h 是硬节拍，绿窝 2 线收益只剩增速、非增率） |
| A3 | 绿窝 CD 挂窝/挂精灵等价 | §4.2 催化的对象 | 低 |
| A4 | 分组命中后按母本均匀权重落蛋 | §4.2 `γ=n/(n-1)` | **高**（改度数加权则 `γ=E/(E−d_A)`） |
| A5 | 档位（大块头）确定遗传 | §2.4 `P_useful` | 中 |
| A6 | 蛋未取走→该母窝所有边失效并重分配 | §2.3/§4.2 | 中 |
| — | 绿窝 2 线在蛋神几何下必为「V 形/同组」 | §3/§4.1 M2 结论 | 高（若游戏真按边判 M1，则 V 形照样给 2× 增益） |

**最大不确定性**：**判定模型到底是 M1 还是 M2**（§3 争议项 2）。它决定：
- 绿窝 2 线值不值（M1 值 / M2 不值）；
- 隔离式要不要为绿窝破例；
- 贪心排序里「绿窝度数增益 ε」要不要保留。

**建议**：用一个**可控实验**判定——同一绿窝分别配 1 条、2 条线（其余不变），记录**平均进 CD 时间**：若 2 线显著更快 → M1；若几乎不变 → M2。实验前，产品上对「绿窝第 2 条」给**保守软奖励**（ε 小），避免误信 M1 造成无关蛋。

## 9. 给代码/算法（任务 B）的模型侧接口建议

- 把模型层抽成**纯函数**：输入 `(布局几何参数 D、判定模型 M1/M2、λ、r_tier、精灵图)`；输出 `{每个配对的 Λ_p, 每个缺口的 Λ_j, 绿窝周期 C_A, 催化因子 γ}`。

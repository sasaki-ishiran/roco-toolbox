## 2. 看板

- [ ] 两个账号时出现**账号筛选**条；点掉一个 → 「账号（1/2）」，进度跟着变
- [ ] 账号筛选**三页共用**：在覆盖度取消一个，切回看板也是取消状态
- [ ] **当前模式**开关存在：默认「**追满分**」；点「追双牌」→ 全程序（覆盖度 / 换什么 / 我的精灵 / 配窝）跟着换口径
- [ ] 切到追双牌后，档位文案不再带「满分」前缀（「满分大婉」→「大婉」）；刷新页面模式还在
- [ ] 「种公全收集」卡是 **已通 N / 14**，整卡可点 → 跳「我的精灵 · 种公视角」
- [ ] 「母本全收集」卡标题带档位（默认 **满分大婉**）；点下面「满分小婉」→ 标题与数字跟着换
- [ ] 「下一步建议」是**三条**「去换XX（组）」（如「去换平和白发懒人（巨灵组）」），**没有**「的蛋」、**没有**「补齐母本」、全页不出现「去抓」
- [ ] 「配窝建议」是**最多 6 条**、每条两行（`组 · 性格 · 档位` / `学院小窝 A ♀100dB ↔ 普通小窝 B ♂100dB`），一公一母
- [ ] 导入后「本次导入新增」里，**档位达标的公即使性格不在目标池也会被列出**（如「满分小婉 · 懒散」）
- [ ] 「数据」卡片：按钮是「导出全部数据」「**合并导入**」，下面一行说明换设备怎么用

## 3. 覆盖度

- [ ] 标题旁显示当前口径小字（如「· 追满分」）
- [ ] 主数字是 **已通 N / 14 组**
- [ ] 蛋组默认**收起**（点「蛋组（14/14）」才展开）；顶部**没有**八大性格栏
- [ ] 展开某蛋组 → 「本组性格」带**绿点标注推荐**；点一下**只改这一组**
- [ ] 档位按钮文案随模式：追满分 = 满分大婉…，追双牌 = 大婉…
- [ ] 明细四态各看一格：已有种公 1 行 / 可直接迭代 2 行 / 有满分缺种公 1 行 / 完全空白无精灵行
- [ ] 带形态的精灵显示**官方名**（下划线），如 `鸭吉吉_等一等鸭`

## 4. 换什么

- [ ] 顶部「共 N 条 · 其中 N 条一只顶两组」
- [ ] 列表项是「**性格 + 精灵名**」（官方名下划线），如 `平和白发懒人`、`固执雪绒鸟_夏天的样子`；
      **不出现**「的蛋」
- [ ] 徽标「补 1 组 / 补 2 组」，第一条是补 2 组；不出现「可选 N 种」
- [ ] 绿窝 100% / 普通窝 60% 可切
- [ ] 勾 2 条 → 「复制选中 2」→ 粘贴格式（两种窝都带前缀、不带「的蛋」）：
  ```
  绿窝满分大婉
  平和白发懒人
  固执雪绒鸟_夏天的样子
  ```
- [ ] 切普通窝再复制 → 首行是 `普通窝满分大婉`
- [ ] 切到追双牌后，首行是 `绿窝大婉`（无「满分」）
- [ ] 「全选」→ 变「取消选择」；候选里**不会出现进化形态**

## 5. 我的精灵

- [ ] 视图切换下方显示「当前模式 · 追满分 / 追双牌」
- [ ] 「全部」：筛选区默认展开（2026-10-05 改）；卡片一行两张
- [ ] **种公视角**：名单 = 公 + 档位达标（**性格不当门槛**）——性格不在目标池的合格公（如「满分小婉 · 懒散」）也会列出来
- [ ] 顶部两行筛选：**档位**（满分大婉/小婉/大粗/小粗）+ **性格**（八大池），都可多选、不选=全部；
      提示行是「手里的种公（公 · 档位达标）N 只 · 其中覆盖当前目标 M 只」
- [ ] 种公卡片上**不再**有「巨灵组·固执 / 拟人组·固执」这类标注
- [ ] **母本视角**：已收集按**四档各自一节**（满分大婉默认展开，**两列卡片**）
- [ ] **待补齐母本**：默认收起；展开后有**搜索框**（按名称/图鉴号）；每行带现状标签（无母本 / 不够满分）
- [ ] 勾选一条 → 出现「**计划收集**」区（置顶）；点「移除」→ 计划区消失、候选回来
- [ ] 导入新数据后若计划里的链达标 → 数据卡片出现「**计划收集达成 N 个：…**」

## 6. 多设备合并

- [ ] 手机导出 → 微信发给自己 → 平板「合并导入」→ 平板上两边账号**都在**（旧的会只剩一份）
- [ ] 同账号取较新的那份：拿一份旧备份导入，应提示「保留本地较新的 N 个」且本地数据没变
- [ ] 微信里点开备份 json →「用其他应用打开」→ 洛克工具箱 → 自动按**合并导入**处理（要 1.1.3）
- [ ] 「导入抓包数据」入口选中一份备份文件，也被认成备份而不是报错
- [ ] **计划收集**也随备份走：A 设备勾了几条 → 导出 → B 设备合并导入 → B 的计划里也有
      （合并取并集；同一条不会重复）
- [ ] 口径冲突时**本地优先**：B 设备自己选过「追双牌」，导入 A 设备的追满分备份后仍是追双牌

## 已知不做 / 已知缺陷（不是新 bug）

- **APK 里「导出全部数据」是坏的**（已知、待修）：`blob:` 下载在 WebView 里被静默忽略。
  **别在 APK 里点导出**；也**别清理 App 数据或卸载重装**——修好之前 APK 里的数据没有导出路径。
- **大备份走分享有截断风险**（>1 MB）：壳目前把分享内容当文本注入，下一版（1.1.4）会改成字节通道。
- 覆盖度页还留有少量解释性文字（**文案专项**未做）；`breedPlan.reason` 仍是死代码。
- 没有形态的 311 个物种显示物种名（本来就无形态）。
- `迪莫`、`凡雀`：`stage=1` 但上游没有它们的蛋道具。

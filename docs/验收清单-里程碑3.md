## 三、你手动验收的 8 项

| # | 操作 | 预期结果 |
|---|---|---|
| 1 | 「看板」导入四个账号（可一次多选） | 种公 `10 / 42`、母本 `190 / 255`，卡上提示「其中优质母本 13 条」 |
| 2 | 看板最下方「下一步建议」 | 建议点名到**具体物种**（如"雪豆丁/森豆丁…拟人组 × 巨灵组"），不再是"某个蛋组" |
| 3 | 切到「覆盖度」页 | 看到 14 个蛋组的四态矩阵：已有种公 / 有母本可孵 / 有满分缺种公 / 完全空白；顶部总进度与看板一致（10/42） |
| 4 | 点某个蛋组行 | 展开该组的性格明细 |
| 5 | 切到「抓什么」页 | 候选清单点数名到物种，每张卡显示两个蛋组、共同目标性格、能补齐哪些缺口；**首位是白发懒人/雪豆丁/森豆丁这类「拟人组 × 巨灵组」物种** |
| 6 | 回到「我的精灵」 | 卡片「体型」显示体重百分位（如 `34.5%`、`98.4%（大块头）`），非大块头也能看出多大 |
| 7 | 「我的精灵」翻页处 | 每页档位 20 / 50 / 100 可切换，切换后回到第 1 页 |
| 8 | 手机视口（约 390px） | 四个页签都能点，无横向滚动 |

## 五、补充验收（Task 4 / Task 5 已完成，多加两条）

| # | 操作 | 预期结果 |
|---|---|---|
| 9 | 看板滚动到「配窝建议」卡片 | 给出父本 / 母本 / 期望产出，并明确写出**「哪只放学院小窝、哪只放普通小窝」**（不出现距离字样）；若没有任何亲本自带目标性格，则显示说明文案（提示需要一只「该蛋组 + 大块头 + 100dB + 目标性格」的精灵）而不是硬凑一对 |
| 10 | 双击 `刷新数据.cmd` | 输出 `[1/2] 刷新 wiki` → `[2/2] 重建应用图鉴` → `[OK]`；**一次双击即可**，不再需要另外跑 `npm run trim:catalog` |

配窝建议的规则（已确认）：父本与母本都要求「同目标蛋组 + 大块头 + 100dB」；子代声音 =（父+母）/2
向零取整，所以 100 + 99 只能出 99、满分后代必须双满分；物种随母方。
家园共 11 个窝（10 普通 + 1 学院，学院小窝只有一个），两窝需相邻到一定距离（游戏规则）才能配对；
学院小窝里那只精灵**本身就是配对方**，它的性格 100% 传给配对蛋——所以要把「该蛋组 + 大块头 +
100dB + 目标性格」的那只亲自放进学院小窝。产蛋是串行的：一个公同时只与一只母本生蛋，取走蛋后
其他可配对的母窝会继续生蛋，一个母窝同时只能有一颗蛋；默认一公一母配对，多出来的窝默认摆母本排队。

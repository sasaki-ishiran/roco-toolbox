# 各蛋组推荐性格排序（按 wiki 的 PVP 推荐统计）

## 数据来源与方法

- 数据：wiki 模块 `Module:Pets/data/TrainingReference` 里每只精灵的 `pvp.nature`，
  形如 `{ [性格id] = 数值 }`，数值最高的即为该精灵的 PVP 推荐性格。
- **2026-10-04（推荐算法专项）**：管线不再只留热度最高一条，改为保留**全量排序候选**
  （`candidates`），`trim-catalog.mjs` 据此把每物种的 **PVP 推荐 top2** 烘焙进
  `catalog.gen.json` 的 `species[].recommendedNatures`。「优质种公推荐」换蛋时优先用
  该精灵自己推荐性格的第一个；没有推荐（如 S4 新精灵）时走**种族值兜底算法**（见下）。
- **计数单位是「一条进化链」，不是图鉴条目**（`evolution_id`）：
  - 同一形态的不同进化阶段（伊雷龙 → 伊兰亚龙 → 伊兰龙）只算一票，
    取阶级最高那条的推荐；并列的多个最终形态取热度更高的那条。
  - **不同形态各算一票**。依据：同图鉴号的多个形态种族值并不相同——全库 81 组同图鉴号条目里
    74 组种族值存在差异（如鸭吉吉：蓬松的样子 物攻95/魔攻35，紧实的样子 物攻35/魔攻95，
    起来鸭 魔攻125），推荐性格也随之不同（开朗 / 聪明 / 胆小）。
  - 一个精灵属于几个蛋组，就给这几个蛋组各记一次；只有「未发现(1)」组的不可孵蛋精灵不参与。
- 覆盖：560 只精灵有可用推荐（594 个条目中 34 个候选为空）。
- 产物：[data/pvp-natures.json](../../data/pvp-natures.json)，随「一键刷新」自动更新。

## 种族值兜底算法（无 PVP 推荐时，2026-10-04）

实现在 `src/domain/studRecommendations.ts` 的 `fallbackNature()`，确定性规则、无学习参数：

| 判定 | 条件 | 推荐性格 | 效果 |
|---|---|---|---|
| 特攻主向 | `spa > atk` | 聪明 | 魔攻↑ / 物攻↓ |
| 物攻主向 | `atk > spa` | 固执 | 物攻↑ / 魔攻↓ |
| 速度型 | `spe > max(atk,spa) + 10` | 胆小 | 速度↑ / 物攻↓ |
| 肉盾/辅助 | `hp >= max(def,spd)` 且 `(atk+spa)*2 < hp+def+spd` | 沉默 | 生命↑ / 物攻↓ |
| 兜底 | 其余 | 踏实 | 生命↑ / 速度↓ |

例：未完虫（S4 新精灵，gameId 3542）无 PVP 推荐，魔攻 111 > 物攻 102 → 聪明。

## 结论

优先培养的主流性格仍是这 6 个：**固执、开朗、胆小、沉默、聪明、平和**。

按加成方向归类：物攻=固执；速度=开朗、胆小；生命=沉默、平和；魔攻=聪明。

蛋组差异明显，目标性格应**按蛋组分别设定**：

- 固执当先：巨灵组、动物组、拟人组、大地组、机械组、飞龙组
- 开朗当先：两栖组、天空组、妖精组
- 生命方向当先：昆虫组（平和）、海洋组（沉默）、植物组（踏实）
- 速度方向当先：软体组（胆小）、魔力组（胆小）

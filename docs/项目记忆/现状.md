## 六、已知风险（踩过的坑）

| 坑 | 说明 |
| --- | --- |
| 中文路径构建失败 | Android 原生 CMake/ninja 不认 `D:\desk\洛克工具箱`，必须走 `shell-authoritative` junction |
| **`tsc --noEmit` 会漏错** | 根 tsconfig 没开 `noUnusedLocals`，`tsc --noEmit` 通过不代表能构建；**收尾一律用 `npx tsc -b`**（走 project references 的配置，才报 TS6133）。2026-11-22 F1 就漏过一次，留下一个未使用 import 挡了发版 |
| 发布时清单不同步 | 曾出现主站 1.5.6/40、下载站 1.5.2/36，导致正式用户收不到更新。发版必须回读四份清单 |
| **构建前没 fetch** | 2026-11-23 蛋仓角色筛选那次：从落后的本地 test 构建发版，正式站约 15 分钟回退了 3 个远端提交。**发布前必须先 fetch 并确认 base 与 origin 一致** |
| 交接文档数字会漂 | 历史交接卡的统计（提交差、冲突数）几小时就过期，引用前必须重跑命令 |
| 分支保护对管理员无效 | 直推能成功；保护只防外人 |
| `node_modules` 被清过 | 2026-11-22 中午被清空一次，原因不明；跑测试前先确认 `node_modules/vitest` 存在 |
| 朋友的 fork 曾整支覆盖 | 32 提交、0 冲突但会覆盖 120 个文件；只按切片摘，不整支 merge |
| **本机推不了 `origin`** | 手机环境里 HTTPS 出网被挡（`Failed to connect to github.com port 443`；`ssh.github.com:443` 反而通），而 `~/.ssh` 的密钥身份是 `EavonChan`，对主仓库只有读权限（`Permission to sasaki-ishiran/roco-toolbox.git denied to EavonChan`）。**推送只能走 `fork` 远程**：`git push fork HEAD:refs/heads/<branch>`；推 `origin/test` 必须在电脑端做。2026-11-23 因此本地 `test` 累计领先 `origin/test` **14 个提交**（13 个是历史会话未推的） |

# 产品交互规范（2026-10-24 重构；2026-10-25 控件收紧）

本文件固定最小控件与页面语义。新页面优先复用 `src/ui/primitives/`，不要各写一套外观。

> 2026-10-25 用户拍板：全站控件整体收紧，不再一律 44px。统一分档见第 3 节；
> 小组页改为「本地缓存先出内容、后台刷新」，采集进度走满后自动停止、保存并自动导入，
> 导入完成不自动跳页。

## 1. 三类条件必须分开

| 类别                | 例子                                 | 改变后影响     | 清除规则                   |
| ------------------- | ------------------------------------ | -------------- | -------------------------- |
| 游戏账号范围        | 哪些导入账号参与个人计算             | 个人进度与推荐 | 只能由用户明确选择恢复     |
| 收集目标 / 达标条件 | 种公目标档位、个人母本条件 | 进度分母与缺口 | 只能从目标编辑器改（小组口径 2026-10-29 起无编辑入口） |
| 本页显示筛选        | 搜索、蛋组、成员、只看已拥有         | 只影响当前列表 | 「清除本页筛选」只清这一类 |

- 个人母本与小组标准允许不同，界面必须写清主语（「我的母本达标条件」/「小组口径」）。
  小组口径自 2026-10-29 起只读展示（历史组目标由服务端保留），不再提供修改入口。
- 清除列表筛选不能清目标、个人计划、复制勾选或发布草稿。
- 小组范围只覆盖已共享账号；有人未发布 / 不兼容 = 待确认。

## 2. 空值语义（组件不自行猜测）

| 控件                                  | 空值含义                                           |
| ------------------------------------- | -------------------------------------------------- |
| 普通多选（体型 / 声音 / 蛋组 / 性格） | 该维度**不限**                                     |
| 游戏账号筛选                          | 没有选中任何账号（不是「全部」），必须提供恢复控件 |
| 种公目标（档位 / 蛋组）               | **未设置**，不能当成「已全收齐」                   |
| 搜索框                                | 没有关键词（不是「没有结果」）                     |

**尺寸分档（2026-10-25 起）**

| 档位 | 高度    | 用途                       |
| ---- | ------- | -------------------------- |
| md   | 36px    | 主按钮、表单输入、清单搜索 |
| sm   | 30~32px | 次按钮、页内下拉、紧凑输入 |
| xs   | 28px    | 芯片、分段、数量、文字动作 |

圆角固定：按钮 / 输入 `rounded-lg`，芯片 / 分段 `rounded-md`。不要再写 `rounded-full` 大胶囊按钮
（状态徽标、进度条除外）。主页面导航与弹层主操作仍可保留 40~44px 的独立触区。

文字颜色永远搭配文字，不能只用颜色表达状态。

### 精灵卡与头像（2026-10-27）

- 列表布局：精灵卡**一行四张**（`grid-cols-4 gap-1.5`），头像 56px 居上作主体，名称最多两行，其余信息单行截断；同排卡片等高。
- 卡片信息（从上到下）：头像 → 名称 → 性别+性格 → 体型/声音奖牌 → 体重% · dB → 蛋组 → 位置（账号·盒子·序号）。
- 覆盖范围：精灵卡片 56px；种公推荐 / 换什么 / 配窝配对 / 母本档位 / 覆盖度明细 / 母本链 等**列表行**用 24px 或 20px，统一走 `src/ui/PetAvatar.tsx`。
- 取图：按**形态** `gameId` 拼官方 CDN `.../jingling/{gameId}/icon.png`（256×256 透明 PNG），实现见 `src/domain/petAvatar.ts`；`loading="lazy"`，不阻塞首屏。
- 异色档：**只有异色 / 异色炫彩**取 `icon_yise.png`；**炫彩用原色图**（炫彩是游戏内染色，官方 CDN 没有炫彩立绘，套异色图会把原色精灵显示成异色，2026-10-29 用户反馈伊贝儿 / 云梦豚）。官方没收录异色图时先退回普通头像，再失败才用首字占位（两段兜底，不要直接跳首字）。
- **不加深色底**：头像本身是透明 PNG，直接坐在白卡上；不要再套 `bg-slate-*` 方块（2026-10-27 用户反馈灰底难看）。
- 稀有度改用**图标徽标**（叠在头像右上角）：`/ui/rarity/shiny.png`（异色）、`colorful.png`（炫彩）、`shiny-colorful.png`（异色炫彩），映射见 `src/domain/petIcons.ts`；不再写文字标签。
- 体型 / 声音改用游戏**奖牌图标**（`/ui/medals/1001.png` 大块头、`1002.png` 小不点、`1026.png` 婉转声、`1025.png` 粗嗓门），只在有奖牌 / 声音 ±100 时显示；普通情况留空保持等高。
- 兜底：`gameId` 缺失或图片加载失败（官方未收录的新精灵，如 5075 风暴战犬）时，退化为方形浅灰底 + 名字首字，不留破图。
- 头像纯装饰（`alt=""`），可访问名称仍由卡片标题承担。

### 家园页（2026-10-29，用户手调坐标）

- 精灵卡 `PetCompactCard`：家园 **160×115**、需求中心 **160×120**，两列、列间距 8px；卡片内所有元素绝对定位，坐标以 `PetCompactCard.tsx` 的 `L` 常量为准。
- 元素：头像 40px（scale 1.35）、性别、昵称、性格（右上角）、奖牌、蛋组（两个字）、声音 / 身高 / 体重（两行，标签 + 数值）。
- 卡片固定 160 宽，禁止用 `max-w-full` 等让它在窄容器里被压缩；放不下时改成横向滚动。
- 家园**不显示**小窝位置；需求中心在 `top:105` 居中显示「母本/种公 · 账号 · 盒位」。
- 身高 / 体重保留两位小数；声音显示 dB。
- 学院小窝整张卡绿色。
- 精灵卡上方是「配窝卡片」：按游戏实际配对，一公一母用小头像 + 名字 + 性别展示，顺序与游戏数据一致。

| 奖牌 | 83 | 37 | 0.9 | 体型 / 声音奖牌 |
| 蛋组 | 65 | 60 | 1.05 | 每个标签两个字 |
| 性格 | 125 | 17 | 1.25 | 右上角，与昵称同一行 |
| 声音 | 6 | 80 | 1 | 宽 46，两行：标签 + `dB` |
| 身高 | 54 | 80 | 1 | 宽 50，两行：标签 + 两位小数 |
| 体重 | 107 | 80 | 1 | 宽 50，两行：标签 + 两位小数 |
| 位置 | 8 | 105 | 1 | 宽 144，仅 `variant="demand"` |

使用约定：

- 普通名字最长 5 个字（如「画间法师手」）；**多形态只写基础名**（「雪绒鸟_夏天的样子」显示为「雪绒鸟」），形态由头像区分，完整名放 `title`。
- 卡片内字号 / 字重 / 内边距必须与 `卡片布局编辑器.html` 一致（昵称 14px/700、性别 12px/700、蛋组与性格 8px + `1px 3px`、数值 10px/700、标签 8px），否则同一份坐标在编辑器里规整、到应用里会偏。
- 家园：`<PetCompactCard variant="home" />`，学院卡传 `academy`，整卡绿色。
- 需求中心：`<PetCompactCard variant="demand" roleLabel="母本 / 种公" footer="账号 · 盒位" />`。
- 要调位置 / 大小，先用根目录 `卡片布局编辑器.html` 手调，再把复制的 JSON 的 `left / top / scale` 写回 `L`；不要临时改文档流或加 `pr-*` 补丁。

#### UI 排版调试流程（2026-10-29）

1. 不要先改产品代码猜布局；复制 `卡片布局编辑器.html` 作为可交互稿。
2. 用户可以拖动元素、缩放、双击改文字、开参考线 / 元素边框、用元素列表选重叠元素、置顶、复制布局 JSON。
3. 收到 JSON 后，只把 `left / top / scale` 落到 `L` 或对应组件；不要另写一套排版。
4. 落完后必须出 375 / 390 截图让用户确认，再发 test / 正式。

### 小组卡片（2026-10-27／28；2026-10-29 调整）

- 布局：**一行四列**（`grid-cols-4`），每张卡竖向排列：体型奖牌**左上角**、声音奖牌**右上角**，头像 **56px** 居中，名字在头像正下方，目标性格在名字下面。
- 名字：基础名 + **形态缩略小字**（8px 灰字，`·海神球` / `·夏` / `·首领`）；完整官方名放 `title`，不要只写基础名把形态丢掉（2026-10-29 用户口径，推翻 10-27 的「只写名字」）。
- 性格：**全部展示、不收起**（不再有 `+N` / 收起）；因为放在头像下方，性格再多也不会把头像顶下去，同排头像始终对齐。
- 奖牌：资源卡用当前筛选的体型/声音目标（默认 大块头 + 100dB），需求卡用该需求自己的体型/声音；`+100 / -100` 显示为「婉转声 / 粗嗓门」图标。
- 三种列表（我缺的 / 需求中心 / 共同寻找）统一用同一套卡片结构；共同寻找只是在卡片底部多一行任务动作。
- 资源卡片只保留 **头像 + 精灵名称 + 性格**；谁有、组内有没有、是否可迭代等提示语一律不写，用**边框颜色**（`data-blocked` / `data-self-breedable` / `data-incomplete`）表达状态。
- 「我缺的」排序：分区内**目标性格已收到一部分的蛋沉底**，一个都没收到的排前面（2026-10-29）。
- 发需求仍走顶部批量按钮（勾选卡片 → 发需求弹层）；卡片内只保留撤回 / 完成这类个人动作按钮，不写需求条件与承接人。
- 完成需求（2026-10-28）：本地快照里没匹配到个体时**不再直接拒绝**，改为二次确认「背包里未检测到，确认已完成？」——用户拿到蛋但还没重新采集导入时，点「已完成」即可结单。
- 个人动作按钮一律用小号文字按钮（9px）：撤回是无边框下划线文字，确认撤回/取消是 9px 描边小按钮，不要把卡片撑高。

### 小组页顶部（2026-10-29）

- 组内只保留**一张**顶部卡：收集范围 chips → 收集小组 + 刷新 → 我的资源 + 管理选号 → 「成员与邀请」「新建 / 加入小组」两行折叠。
- 成员与新建 / 加入默认收起，点标题就地展开，不再各占一张卡；`group-list` / `group-card` / `mother-members` / `group-setup` 的 testid 与文案（`N 人 · 组长 X`）保持不变，e2e 依赖。

### 母本详情（2026-10-29）

- 弹窗内完成全部操作：目标只写**体型 + 声音两个标签**（如「大块头」「+100」），不再写「目标：性格 … 体型 … 声音 …」。
- 点「发需求」**就地展开**性格面板：八大性格先出、3 列，其余收进「更多」；已收齐的性格置灰划线、已发过的标绿不可重复；性别 / 体型 / 声音就地选，**体型不给「不限」**；底部「发布 N 条需求」。**不再叠第二层抽屉**。

### 我缺的 / 需求中心（2026-10-28）

- 「我缺的」用**瀑布流**：首屏 24 项，滚到底自动追加；不提供上一页 / 下一页。
- 「需求详情」头部参照家园精灵卡：**名字 + 性格** 一行 → **性别 + 体型/声音奖牌** 一行 → **需求方 + 状态** 一行；不再用「性别 母 · 体型 … · 声音 …」文字行，也不把性格/性别飘到右边留大片空白。
- 「推荐配对」用**家园同款精灵卡**（`PetCompactCard`）：一公一母并排，角色用「母本 / 种公」标签，
  卡片内含头像、名字、性别、奖牌、蛋组、性格，底部写账号 · 盒位；上方先写一句建议
  （能孵出什么 / 还缺哪只亲本）；同一图鉴号有多只时优先取带目标性格的那只。
- **只认配对孵蛋**：本机只有一只、配不出另一半时不算能接单；详情不写「交割精灵 / 已有现货」。

### 种公阵列（2026-10-28，参考蛋神助手）

- 位置：收集 · 种公页（覆盖度）顶部，跟随「覆盖度」筛选的蛋组与目标性格；下方仍保留按蛋组的缺口明细。
- 行 = 蛋组，列 = 当前档位下所有目标性格的**并集**（出现次数多的在前）；某组没把该性格列为目标时，格子显示淡灰「—」，不算缺口。
- 档位做 **tab**（大婉 / 小婉 / 大粗 / 小粗，只显示筛选里勾了的），一次只看一档。
- 格子：代表种公头像 + 名字；**候选多于 1 只时名字下方显示小数字**。点格子弹层选择代表，候选按「体重更满 → 声音更极端 → 账号 → 名字」排序，可「恢复自动」。
- 代表选择只影响阵列展示，不改背包/共享数据；记在本机 `roco.studMatrixPicks`（键 = `档位::蛋组::性格`），刷新/重开还在；记录失效（精灵没了）自动退回排序第一。
- 没有候选的目标格：先用「优质种公推荐」填一只淡黄推荐卡（右上角「荐」），没有精确推荐时按蛋组兜底一只可出公的蛋物种；点淡黄格可以选小组，把「蛋组 × 性格 × 当前档位」的种公需求发到该组需求中心。都没有才显示「缺」。
- 多账号跨账号混排，候选里标账号。

## 4. 控件行为

### 搜索（`SearchField`）

- 固定在清单顶部，独立于高级筛选；必须有可访问名称。
- 有内容时才出现「清除搜索」，只清这一个词。
- 保留各页现有匹配函数，不宣称拼音或模糊搜索。
- 搜索框独占一行（小组资源页尤其如此）；成员筛选、复选框等放到下一行，不挤压输入宽度。

### 小组页（缓存优先，2026-10-25）

- 首屏先读本机缓存（上次成功的组列表 + 当前组详情），立即显示内容；随后后台刷新。
- 没有缓存时显示「正在读取你加入的小组…」；只有请求确实失败才显示「暂时读不到」，并提供重试。
- 刷新失败保留上次内容并标「离线，显示上次获取的数据」；不能把有缓存的内容清成空白。
- 缓存按工具箱身份隔离；退出小组 / 被移出 / 组不存在时清掉对应详情。
- 「管理选号」是展开 / 收起开关，再次点击必须能收起；草稿未发布时收起后仍要提示「有未发布的修改」。
- **组头卡只留三行**（2026-10-26 精简）：组名 / 人数 / 组长、口径摘要、我的资源状态与按钮；
  选号编辑器收进「管理选号」，不再单独占卡。
- **2026-10-29 起「改口径」正式下线**（用户拍板，`GroupTargetEditor` 已删除）：口径摘要只读展示，
  小组不再提供任何目标编辑入口。
- **成员与邀请、新建 / 加入小组默认收起**，各留一行标题；已入组时新建 / 加入放在成员区下面，
  个人求蛋模式仍默认展开。
- 成员行显示「已结 N 单」与「N 天未更新」（超过 7 天标红）；组长才有「移除」，不能移除自己。

### 看板（2026-10-25）

- 配窝建议是核心亮点，**完整摆位图与逐条配对直接放在看板**。
- 「去看怎么迭代」「去看怎么收集」紧跟「能自己迭代 N · 未收集 M」摘要行；不再有「去配窝」入口，
  也不再有独立的「自己孵」页面。
- 收集页的「种公」只保留**覆盖矩阵**；求蛋清单已迁到「小组 · 个人求种公」。
- 配窝卡片为空时必须按状态写清原因：未设置目标 / 已全部收集 / 没有能自己孵的方案。

### 小组收集二期（2026-10-25 夜）

- **2026-10-27 起小组只剩一种「收集小组」**（用户拍板）：不再让用户选母本收集 / 种公收集，
  服务端也只接受 `mother`；旧种公组按决策 F 备份后删除，个人求种公页保留不动。

### 本机采集（2026-10-25）

- 采集进度走满（内容稳定、没有新流量）后自动停止、保存，并**自动解析导入**，不需要用户再点
  「解析并导入并确认」；每个采集会话只自动停止 / 自动导入一次（标记在模块级，切页重挂不会重复）。
- **走满即定稿**：进度条走满后立即停止读快照与解码，之后再有数据包也不复核；
  不允许出现「有新流量，正在复核」把已走满的进度打回稳定等待，拖住自动停止与导入。
- **弹窗要等结果**：等文件真正落盘 → 自动导入 → 私有云同步到终态后才弹「导入完成」；
  等待期间只在采集卡片里显示「正在保存 / 正在导入 / 正在同步」，不要先弹一个「正在准备导入」的空弹窗。
  刚停完就调用导入会被壳拒绝（请先停止采集并等待保存完成），必须重试而不是直接判失败。
- 完成弹窗只有「取消 / 上传蛋神助手」：取消**仅关闭弹窗**；上传也会先关掉弹窗，进度在原包列表里看。
  弹窗正文带出本机导入结果、私有云同步状态与「小组资源需要手动发布」。
- 导入失败 / 等待超时也要弹「导入未完成」并说明可在文件列表点「解析并导入」重试，不能一直停在准备中。
- 导入完成后**不自动跳看板**（含分享导入）：结果留在「我的 · 游戏数据」，用户在本页看进度与结果。
- 采集进度与解析结果跨页保留：切到其他页再回来先从缓存恢复，不清零、不从头开始。
- 「上传蛋神助手」按钮常驻：上传成功后不消失，变为「重新上传」；失败可重试，等待云端确认可继续查询。
- 游戏数据页始终显示「本机采集」入口：没有安卓采集桥（网页版 / 旧安装包）时显示说明卡，
  明确告知改用「导入游戏数据」手选文件，或更新安卓安装包；不能整块静默消失。
- 低频说明（外部文件导入 3 步上手等历史入口）不再重复展示；采集步骤只保留当前最短路径。

### 重置导入数据（2026-10-25）

- 「重置导入数据」必须清空账号快照**及所有由它派生的页面状态**：导入历史、本次新增、
  账号筛选、清单筛选、母本计划、种公推荐里的「已换到」、导入三阶段反馈。
- 保留：目标档位、母本达标条件等设置，工具箱身份，以及服务器上已发布的小组资源。
- 确认文案必须写清「会清空什么 / 会保留什么」，不能只写「规划设置会保留」。

### 单选（`InlineSelect`）

- 页内展开，不用系统 `select`。
- 打开时焦点落在当前项；选择、Esc、点外都关闭并返回触发按钮。
- 方向键切换选项；禁用项不能选。
- 选项使用原生 radio，视觉沿用看板下拉。

### 分段（`SegmentedControl`）

- 具名 `group` + `aria-pressed`；一个分段只表示一种互斥视角。
- 不把不同维度混成一排，不用实现不完整的 `tablist`。

### 多选（`FilterAccordion` / `FilterPanel`）

- 维度互斥展开；点选项**不自动收起**，可连续多选。
- 已选摘要常显；已选但当前 0 命中的项仍可取消。
- 「清除本组」只清该维度。

### 按钮与输入（`Button` / `Field`）

- 主 / 次 / 文字 / 危险四层；忙碌态实际 `disabled` 并 `aria-busy`。
- 输入错误用 `aria-invalid` + `aria-describedby` 关联，不只用红色边框。

### 范围摘要（`ScopeSummary`）

- 必须写清「谁的什么条件」；来源时间与「调整」动作按需出现。
- 只展示传入的事实，不推断收集状态。

## 5. 状态反馈

同一处状态必须区分：无数据 / 无匹配 / 全收齐 / 未设置 / 不可计算 / 待确认 / 缓存或离线 / 失败。

- 有旧内容时刷新失败：保留旧内容并显示上次获取时间。
- 全部收齐时写「已全部收集」，不能写「导入后给出建议」。
- 未发布或版本不兼容时写「不能计算」，不能写「没有」。
- 网络在线状态、源数据时间、资源可比较性分别展示。
- **切页不闪（2026-10-25）**：有进程内缓存的数据先同步出内容，再后台刷新；
  「我的」的云端账号信息要缓存上次结果，不能每次重挂都先显示「云端版本 暂无」；
  账号数直接读内存快照，不再异步算大小后改文字。
- **占位高度稳定**：采集状态 / 本地数据尚未读完时用同高骨架占位，不能整块 `null` 后突然出现。

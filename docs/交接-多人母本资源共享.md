## 六、已知差异与未覆盖

1. **页面内切换页签**不会拦截未发布的选号草稿：目前只有 `beforeunload`（关闭/刷新）提醒。设计要求的「页面内离开确认」未做，避免改全局导航。
2. live e2e 覆盖「多身份/多设备查看与共享」，**没有**用浏览器走完整「导入 fixture → 勾选 → 预览 → 发布」链路；发布链路由 API 集成测试 + 组件测试覆盖。
3. `tools/test/verify-mother-groups-schema.mjs` 使用 `node:sqlite`：需要 Node ≥23.4（本机 24.22.1）。Node 22 需加 `--experimental-sqlite`。
4. 组列表只在进入页面/切换组时刷新，成员数不会随轮询实时更新；当前组详情每 15 秒刷新。
5. 读取限流用例会真实打满 1800 次/账号，单次约 37 秒（本地）。
6. 二期：自选母本体型/声音口径、每个小号独立全收集、组主转让/移除成员、发布自动化。

# 开发规划：里程碑与解锁的能力

**怎么读这份文档**：每个里程碑都是一个能独立跑起来、你能亲手验收的版本。看「完成后你能做什么」这一栏，
判断排期要不要调整。工作量用"任务数"表示（一个任务 = 一次可独立验证的代码改动，含测试）。

---

## 里程碑 1 · 数据底座与看板 ✅ 已完成（2026-09-26）

**交付**：手机能打开的看板；导入抓包 JSON；两块进度；3 条粗粒度建议；重置按钮；数据来源署名。

| 完成后你能做什么 | 现在还做不到 |
|---|---|
| 把四个账号的抓包 JSON 导进去，看到种公网络 `10 / 42`、母本集齐度 `190 / 255` | 看不到具体是哪些精灵 |
| 一键重置，逐个账号导入验证 | 不能按账号分别查看 |
| 看板给出 3 条方向性建议（"去抓巨灵组种公"） | 建议不点名具体精灵 |
| 重复导入同一账号不会重复计数 | 不能按大块头/满分/公母筛选 |

**已知小瑕疵**：42/42 全达成后建议文案会自相矛盾；导入一次只能选一个文件；前端包 890KB（gzip 236KB）。

## 里程碑 2 · 我的精灵（你这次提的两件事都在这里）

**交付**：一个能查、能筛、能定位的精灵清单，覆盖「种公」和「母本」两种视角。

| 完成后你能做什么 | 对应你提的问题 |
|---|---|
| 按账号筛选（单选/多选），看每个账号分别有什么 | 「导入了四个之后固定成 10、190，不知道每个账号有哪些」 |
| 叠加标签筛选：大块头 → 婉转声 → 满分 → 公/母 → 异色 | 「不能直观看到种公有哪些精灵」 |
| 每只精灵显示**账号 + 盒子编号 + 盒子内位置 + 形态 + 性格 + 分贝 + 体型** | 「在精灵盒子的什么位置」 |
| 切到「母本视角」看还缺哪条进化链，已收集的排在前面 | 母本存在同样的问题 |

**必须先做的一处数据改造**：现在的解析**没有保留盒子位置**（`group`/`boxNumber`/`slotOrder`），
所以这一版完成后，你需要**重新导入一次抓包 JSON**，旧快照里没有这些字段。

**工作量**：约 5 个任务（扩数据模型 + 索引与筛选 + 列表虚拟滚动 + 母本视角 + e2e）。

## 里程碑 3 · 覆盖度矩阵与点名建议

**交付**：14 蛋组 × 目标性格的四态矩阵；点名到具体物种的抓取建议；配窝建议。

| 完成后你能做什么 | 说明 |
|---|---|
| 展开矩阵，每格看到「已有种公 / 有母本可孵 / 有满分缺种公 / 完全空白」 | 对应设计文档 §7.2 |
| 建议点名到物种，例如"抓 雪豆丁（拟人组 × 巨灵组，一只顶两组）" | 用已算好的 42 目标与双蛋组性价比 |
| 给出下一窝配哪两只、期望产出（物种/蛋组/体型/声音/性格） | 由母方决定物种、双满分出满分、双大块头出大块头；家园 11 窝（10 普通 + 1 学院）、两窝曼哈顿距离 ≤ 2 可配对，学院小窝那只精灵本身就是配对方、性格 100% 传给配对蛋 |

**工作量**：约 4 个任务。

## 里程碑 4 · 数据更新与部署

**交付**：手机内一键刷新上游图鉴；部署到 HTTPS 托管，手机装成应用、可离线；看板导出分享。

**进度（2026-09-26）**：✅ HTTPS 部署已完成 — 线上地址 https://roco-toolbox.pages.dev/（Cloudflare Pages，含 PWA manifest 与 Service Worker，可添加到主屏幕、可离线）；
✅ 数据导出/导入备份已完成（手动共用一份数据）；✅ 导入后「本次新增」提示已完成（只列合要求的新增精灵 + 所在盒子，见 `docs/验收清单-本次导入新增.md`）；⏳ 手机内一键刷新上游图鉴仍未做（游戏版本更新时仍需在电脑上跑 `刷新数据.cmd`）。

| 完成后你能做什么 | 说明 |
|---|---|
| 在手机上点一下刷新图鉴/性格/PVP 推荐，不用电脑 | wiki 接口允许跨域，浏览器内可直接抓取解析 |
| 手机"添加到主屏幕"，断网也能打开 | 需要部署到 HTTPS（GitHub Pages / Cloudflare Pages / Vercel） |
| 导出一份单文件看板，能离线打开也能发给别人 | 同时解决分享 |

**工作量**：约 4 个任务。

## 排期建议

- **最影响日常使用体验的是里程碑 2**——它直接解决你这次提的两个痛点（不知道每个账号有什么、
  看不到具体精灵和盒子位置）。建议紧接着做。
- 里程碑 3 是"抓什么最划算"的最后一公里，但它的价值依赖里程碑 2 的清单视角，顺序不宜颠倒。
- 里程碑 4 只影响"方便程度"（不用开电脑、能离线），功能上不新增信息，放最后做最划算。
- 三个小瑕疵可以在里程碑 2 里顺手修掉（多文件导入、建议文案、包体裁剪）。

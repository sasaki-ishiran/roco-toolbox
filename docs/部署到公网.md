---

局域网地址（`http://192.168.x.x:4173`）只有连同一个 Wi-Fi 的设备能打开，而且电脑必须开着。
部署到免费的 HTTPS 托管后，会得到一个**公网网址**：她在任何地方、用流量也能打开，
还能"添加到主屏幕"当应用用（可离线打开）。

**应用本身是纯静态的**，服务器上只有代码，**你们的账号数据仍然只存在各自手机/电脑本地**。

## 一、先构建线上版

双击 **`构建线上版.cmd`**（在 `D:\desk\洛克工具箱` 下）。它会执行构建，并自动打开 `dist` 文件夹。

> 要上传的是 **`dist` 文件夹里的全部内容**（index.html、assets、sw.js、manifest.webmanifest、图标等）。

## 二、方案 A（推荐）：Cloudflare Pages 直接上传

免费、不需要命令行、不需要 GitHub 账号（邮箱注册即可），大约 5 分钟。

1. 浏览器打开 https://dash.cloudflare.com/ 注册或登录。
2. 左侧选 **Workers & Pages** → **Create** → **Pages** → **Upload assets**。
3. 项目名随便起（例如 `roco-toolbox`），然后**把 `dist` 文件夹拖进上传区**，点 **Deploy**。
4. 部署完成后会得到一个网址，形如 `https://roco-toolbox.pages.dev` —— 这就是公网地址。
5. 手机上打开它 → Chrome 右上角菜单 → **添加到主屏幕** → 桌面上就出现「洛克工具箱」图标。

## 三、方案 B：Netlify Drop（更简单，但项目名是随机串）

1. 浏览器打开 https://app.netlify.com/drop
2. 把 `dist` 文件夹拖进去，等它部署完。
3. 登录（GitHub/邮箱）后可以保存站点、改名字，得到 `https://xxx.netlify.app`。

## 四、方案 C：GitHub Pages（需要 GitHub 账号，适合以后自动部署）

1. 新建一个 GitHub 仓库，把本项目推上去（需要先安装 `gh` 或配置访问令牌）。
2. GitHub Pages 的项目地址是 `https://<用户名>.github.io/<仓库名>/`，属于子路径，构建时要指定：

   ```powershell
   $env:VITE_BASE='/<仓库名>/'; npm run build
   ```

3. 仓库 **Settings → Pages**，Source 选 **GitHub Actions**（或把 `dist` 推到 `gh-pages` 分支）。
4. 需要的话我可以帮你生成 GitHub Actions 工作流，之后每次 `git push` 自动部署。

## 五、"共用一份数据"怎么做

服务器上**没有**你们的账号数据，所以两人之间共用一份要靠手动同步（已实现）：

1. 你：看板 → **导出全部数据** → 得到 `洛克工具箱备份-日期.json`。
2. 把文件发给她（微信/QQ 都行）。
3. 她：打开同一个公网地址 → 看板 → **导入备份** → 选那个文件（会提示覆盖，确认即可）。

之后谁更新了数据（抓到新精灵、孵了新蛋），重复"导出 → 发送 → 导入"即可。

> 以后如果需要"自动同步"，就要额外做一个后端（例如 Supabase 免费版）——那是下一步的事。

## 六、以后改了代码怎么更新

- 方案 A / B：重新双击 `构建线上版.cmd`，再把新的 `dist` 上传一次（Cloudflare Pages 可以重新上传覆盖；Netlify 可以拖到同一站点）。
- 方案 C：`git push` 后自动部署（配好 Actions 的话）。

    列表行数为什么没变多：当前设计里「列表可视高度 = 地图高度」（bodyHeight = MAP_SIZE），
    地图缩小只会让列表变宽、文字更宽松；要让面板变矮就把「列表高度跟随地图」打开（方案一 -18dp、方案二 -30dp），
    代价是可见行数变成 2 行多。要让列表多出行，必须把面板改高，和「缩小地图」目标相反。

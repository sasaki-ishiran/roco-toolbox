# 里程碑 1 验收清单（数据底座与看板）

**这一版能做什么**：手机上打开一个看板 → 导入抓包 JSON → 看到「种公网络」与「母本集齐度」两块进度，
以及 3 条下一步建议。

## 一、怎么跑起来

```powershell
cd D:\desk\洛克工具箱
npm run dev
```

浏览器打开终端里显示的地址（默认 `http://localhost:5173`）。手机上访问时用电脑的局域网地址，
例如 `http://192.168.x.x:5173`（开发模式下这样够用；正式部署方式见设计文档 §8）。

## 二、你手动验收的 6 项

| # | 操作 | 预期结果 | 不通过说明什么 |
|---|---|---|---|
| 1 | 打开首页 | 看到标题「洛克工具箱」、两块进度卡、「下一步建议」卡、底部数据来源与 CC BY-SA 4.0 署名 | 页面空白或报错 |
| 2 | 首次打开（没有数据） | 两块卡显示 `0 / 42` 与 `0 / 255`，并有「还没有数据」提示 | 空数据会崩 |
| 3 | 点「导入抓包数据」，选 `补充数据` 里的 **测试甲** JSON | 进度变为种公 `9 / 42`、母本 `129 / 255`，并出现 3 条建议 | 导入链路不通 |
| 4 | 再依次导入另外三个账号（测试乙、测试丁、测试丙） | 进度变为种公 **`10 / 42`**、母本 **`190 / 255`** | 多账号合并或连接键有问题 |
| 5 | 把同一个账号的文件**再导入一次** | 进度数字**不变**（不会翻倍） | 重复导入会重复计数 |
| 6 | 手机或浏览器的窄窗口（约 390px 宽） | 没有横向滚动条，按钮可点（点击区 ≥ 44px） | 布局有问题 |

## 三、你可以自己跑的技术验证（可选）

```powershell
npm test        # 预期：6 个测试文件、22 个用例全部通过
npm run e2e     # 预期：2 个浏览器用例通过（含"导入→出现进度与建议"）
```

## 四、数据更新方式（本版）

上游图鉴数据仍通过双击 `刷新数据.cmd` 更新（手机内刷新是后续里程碑）；
你的账号数据通过看板上的「导入抓包数据」按钮更新。超过一周没导入，看板顶部会提醒。

## 五、本版**还没有**的功能（后续里程碑，别当成 bug）

- 标签筛选（大块头 / 婉转声 / 满分 / 公母）——设计文档 §7.1
- 覆盖度矩阵明细（蛋组 × 性格 四态）——设计文档 §7.2
- 具体的抓取建议物种清单（当前建议只到"哪个蛋组"，没有点名物种）——设计文档 §7.3
- PWA 安装与离线（需要部署到 HTTPS 托管）——设计文档 §8
- 母本清单的"已收集 / 未收集"分组展示
- 静态看板导出与分享

## 六、已知小瑕疵（已记账，暂不影响使用）

1. 当种公网络全部 42 个目标都达成后，建议文案会显示"该组还有 0 个目标未覆盖"（自相矛盾）。
2. 导入按钮一次只能选一个文件，四个账号要点四次。
3. 前端包 890KB（gzip 236KB），包含运行时不用的字段，后续会裁剪。

## 2026-10-04 轮（大型功能优化 + 推荐算法专项）

### 本轮已完成

**主界面**

- 顶部 4 个功能标签**常显**：header + TabNav 包进 `sticky top-0 z-50` 容器（App.tsx），
  滚动到底仍可切页签。注意：sticky 容器背景必须不透明（bg-white），否则滚动时透字。

**看板**

- 「本次导入新增」卡：原来「收起」= 清空内存、刷新即丢。改为**卡内本地展开/收起**
  （收起只隐藏正文不删数据），且历史持久化到 localStorage（`roco.lastImportResults`，
  保留最近 5 次）。（ImportResultCard + lastImportStore）
- 新增条目标题/行格式：
  - **新增种公按 4 档分组**（与母本一致，用户拍板：含小不点/粗嗓门种公，不再纠结标题措辞）；
  - 每条改为 `精灵名 性别符号 · 性格 · 组别 · 声音dB · 位置`（母本无组别段）。
- 模式说明文案改为：`追满分 = ±100dB 才算；追双牌 = 有体重+声音双牌就算。`
- 主页母本列表：可收起（默认收起，方便同时看进度与建议）；行格式去重，
  改用 `speciesDisplayName()`（多形态显示 `海枝枝_碧蓝珊瑚`，不再「A | A」重复）。
- 母本全收集卡加「看我的待补齐母本」跳转（复用 App 的 myPetsView 机制）。
  **ProgressCard 加 `actionTestId`**：页面上多张可点卡时用不同 testid，避免 Playwright strict mode 冲突。

**优质种公推荐（原「下一步建议」）**

**我的精灵**

**求蛋清单**

**配窝建议**

- 展示格式：`目标：蛋组 · 目标性格 · 满分大婉` / `学院小窝 A ♀ · 性格 ↔ 普通小窝 B ♂ · 性格`
  （亲本行显示**性格**，不再只显示 dB）。
- **学院小窝只有一个 → 建议列表只有第一条写「学院小窝」，其余全部按普通小窝写**
  （前端 slice 方案：index 0 学院措辞、index≥1 普通措辞。取舍：学院唯一性是展示层物理约束，
  不进领域模型；若未来其他页面复用配窝列表再下沉）。
- 段尾规则提示：`学院小窝只有 1 个；普通小窝里每只亲本有 30% 概率把自己的性格遗传给蛋（双方同性格时 60%）。`
- 删除了 `breedPlan.reason` 死字段（UI 本就不渲染，仅测试断言；配窝改版一并清理）。

**推荐算法专项（完整）**

- 领域规则修正（用户拍板，重要！）：普通窝性格遗传不是旧的 60%：
  **每只亲本 30% 遗传自己性格；父母同性格 → 60%；迭代蛋（一方非目标）→ 30%**。
  旧文档（数据字段说明.md）的 60% 已修正。
- 管线：`pvp-natures.mjs` 不再只留最高热度一条，保留**全量排序候选**（`candidates`）；
  `trim-catalog.mjs` 烘焙 **stats 六围**（625 全覆盖）+ **recommendedNatures top2**；
  产物 `catalog.gen.json` 增加字段。
- 兜底算法（`src/domain/studRecommendations.ts` `fallbackNature()`，确定性规则）：
  特攻主向 spa>atk → 聪明（未完虫 3542 魔攻111>物攻102 ✓）；atk>spa → 固执；
  spe > max(atk,spa)+10 → 胆小；血高攻低 → 沉默；否则 → 踏实。
- 接入：`computeStudRecommendations` 的性格蛋 = **该精灵自己能换到的性格**（PVP top1 或兜底），
  不再用清单目标性格——「开朗白发懒人」这种没人孵的性格蛋换不到，不该被推荐。
  物种完全无推荐信息时不推这条。swapPlan/studTargets 槽位口径**不动**。

**APK 1.1.4（versionCode 8）**

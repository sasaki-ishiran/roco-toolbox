# 里程碑 2 验收清单（我的精灵）

**这一版新增**：第二个页面「我的精灵」——能按账号筛选、按标签叠加筛选、看到每只精灵的盒子位置，
并能切换「种公视角」「母本视角」。顺带把多文件导入、包体、建议文案三处小瑕疵一起修了。

## ⚠️ 先做这一步：重新导入一次抓包 JSON

盒子位置是这一版才解析的字段，**之前导入的旧快照里没有**，会显示「未知」。
要看到真实盒子位置，请到「看板」点导入、重新选一次你的抓包文件（现在支持一次选多个）。

## 一、怎么跑

```powershell
cd D:\desk\洛克工具箱
npm run dev
```

浏览器打开终端显示的地址（手机上用同一局域网的地址）。

## 二、你手动验收的 8 项

| # | 操作 | 预期结果 |
|---|---|---|
| 1 | 「看板」页导入四个账号（可一次多选四个文件） | 种公 `10 / 42`、母本 `190 / 255` |
| 2 | 切到「我的精灵」页 | 出现精灵卡片，每张含：名称+图鉴号、性格、性别、分贝、体型、**账号**、**盒子** |
| 3 | 依次点「大块头」→「婉转声」→「满分」三个标签 | 列表逐步收窄，最后只剩大块头且分贝 100 的精灵 |
| 4 | 点某个账号标签（如「测试甲」） | 只剩该账号的精灵 |
| 5 | 切「种公」视角 | 列表全是「大块头 + 100dB + 公」 |
| 6 | 切「母本」视角 | 「已收集」分组在前、且每条能看到具体母本精灵与它的盒子；「未收集」在后 |
| 7 | 回「看板」点「重置导入数据」 | 两块进度回到 `0 / 42` 与 `0 / 255` |
| 8 | 窄窗口（约 390px） | 无横向滚动，标签与按钮可点（≥44px） |

## 三、技术验证（可选，我都跑过）

```powershell
npm test        # 预期 7 个文件、35 个用例全过
npm run e2e     # 预期 6 个浏览器用例全过
npm run build   # 产物约 238 kB（gzip 70 kB），比上一版 887 kB 小很多
```

## 四、已知限制（下一步处理）

1. **上游数据更新后需重跑一次数据裁剪**：本版为了让手机端包体从 887kB 降到 238kB，把图鉴裁剪成
   `src/data/catalog.gen.json`。双击 `刷新数据.cmd` 之后还要跑一次 `npm run trim:catalog`，
   否则应用里仍是旧图鉴。我计划在里程碑 3 把这个步骤合进刷新流程，做成一步完成。
2. 母本视角的「未收集」只列出进化链名，没有给出"去哪个地图抓"（这是刻意的：游戏内有快速追踪）。
3. 标签里目前只有正向的「婉转声」，粗嗓门（-96~-100）还没做标签。

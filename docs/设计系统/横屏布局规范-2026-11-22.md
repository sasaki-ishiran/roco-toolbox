# 横屏布局规范（2026-11-22）

> 由来：2026-11-22 家园页连续改了「账号胶囊自适应 → 顶栏加蛋仓 → 我的蛋仓横屏三栏 → 纵向标题栏 → 收起后加列」一整轮。
> 规则当时散在 `src/index.css`、`Home.tsx`、`EggStockPanel.tsx` 三处，本文件把这套口径收口；后续横屏页面照此执行，不再各自发明。
> 同一天后半段把骨架抽成共用 class / 组件，切了「我的」和「换蛋」两页（含换蛋 → 蛋仓子页）。
> 证据：本文条目都对应 test 分支 `2d89e17` / `75a8ba6` 与 390 / 844 / 1120 三种尺寸的实测截图。

## 一、四条总原则

| # | 原则 | 落到哪 | 反例 |
| --- | --- | --- | --- |
| 1 | 竖屏是母本 | 横屏只重排，不加功能、不删信息 | 横屏多出一块竖屏没有的面板 |
| 2 | 高度最稀缺 | 标题 / 筛选 / 动作能进右侧栏，就不占顶部 | 顶栏 + 页标题 + 搜索 + 条件叠四层 |
| 3 | 宽出来的是列数，不是卡片宽度 | 卡片固定宽，`auto-fill` 排几列算几列 | 横屏把 77px 的蛋卡拉到 180px |
| 4 | 状态记住、跨页一致 | 折叠偏好按设备存 `localStorage` | 每次进页面都重新展开 |

## 二、断点（全部是媒体查询，竖屏不命中）

| 判定 | 用途 | 出处 |
| --- | --- | --- |
| `(orientation: landscape)` | 横屏基础：左侧竖栏、根字号、家园与蛋仓的横屏重排 | `src/index.css` |
| `landscape and (max-height: 600px) and (min-width: 760px)` | 手机横屏：家园配窝卡单 / 双列 | `HomePairCards` |
| `landscape and (min-width: 1000px)` | 平板横屏：蛋仓筛选列 13rem → 14rem | `EggStockPanel` 样式 |
| `landscape and (min-width: 1120px)` | 宽横屏：看板、收集左右并排 | `useWideLandscape()` |
| `(orientation: portrait)` | 竖屏专用规则（少用；能用默认样式就别单写） | `src/index.css` |

字号：横屏 `html { font-size: clamp(15px, calc(9px + 0.55vw), 21px) }` → 1rem ≈ 15~21px。
所以**尺寸一律写 rem**：`5.1rem` 卡宽在 844 屏是 77px，在 1280 屏会跟着放大；写死 px 会两头都不对。

## 三、骨架：主区 + 功能列 + 纵向标题栏

```
┌──────────────────────────────┬────────────────┬────┐
│ 内容（蛋卡 / 列表）           │ 功能列：搜索+条件│纵向│ ← 功能列可整列收起
│ 占满剩余宽度                  │ （横屏才出现）   │标题│ ← 标题栏永远在最右
└──────────────────────────────┴────────────────┴────┘
```

- **主区**始终在左，占满剩余宽度；内容从上边开始，不留顶栏空档。
- **功能列**放搜索与筛选条件，宽度 13rem（≥1000px 用 14rem），可收起；竖屏时回到主区上方，顺序固定「搜索 → 条件 → 内容」。
- **纵向标题栏**在最右，固定 2.6rem，放返回动作 / 页面入口 / 视角 / 折叠开关；文字**一行两个字**（返回/家园、我的/蛋仓、收起/筛选、展开/筛选）。
- 标题栏**除筛选开关外一律纯文本**，不画按钮外框、圆角或底色（2026-11-22 晚用户口径）；当前项只靠颜色 + 字重区分。
- 标题栏里**每个组件之间用 1px 分隔线隔开**（直接子项 `border-top`，同一组内的项也各有一条）。
- 页名可以不画：`我的`、`换蛋` 两个主导航页的页名由左侧页签表达，右侧栏不再重复（2026-11-22 晚用户口径）；`RailAside` 仍用 `aria-label` 保留读屏名称。蛋仓子页仍显示「我的蛋仓」。
- 进入这类屏时**顶栏整行隐藏**（`header[data-view="stock"] { display: none }`），页面标题与返回动作移交标题栏，蛋卡直接从最上面开始。
- 没有搜索 / 条件列的页（例如「我的」）只放主区 + 标题栏：同一个 `.rail-layout` 加 `data-has-filters="false"`，少一列；分区导航进标题栏，不额外占顶部。

## 四、家园页顶栏与横屏右侧栏（2026-11-22；2026-11-24 起横屏改右栏）

- 竖屏顺序不变：`账号胶囊 → 蛋仓 → 接单上窝 → 刷新家园 → ?`。
- **横屏（2026-11-24 用户口径）**：顶栏整行不再渲染，`账号 / 接单上窝 / 蛋仓` 搬进右侧 2.6rem 纵向标题栏（`home-rail`），一行两个字；账号下拉从标题栏向左弹（`.home-rail-account-options`），不能被屏幕右缘裁掉。
- **刷新家园留在主区标题行右侧**，不进右侧栏；刷新状态提示仍整行放在标题下方。
- 配窝卡的单 / 双列只看**横屏高度**：`max-height: 600px` 才并排，高度够的平板横屏保持单列；不要按宽度铺多列（2026-11-24 用户纠正）。
- 横屏空态（未登录 / 未入组 / 没导入数据）整卡放在内容区正中，不贴左上角。
- 横屏**未登录**的蛋仓空态不再显示说明，只留 1/3 宽、居中的「去登录」按钮（2026-11-24 用户口径）；未入组 / 读失败仍有说明。
- 账号胶囊（竖屏）：宽度 = 文本宽（`w-auto`），上限 `max-w-[60%]`，超长 `truncate`；不再写死 14rem / 18rem。
- 「蛋仓」是**页内一屏**（`HomeView = 'nests' | 'demands' | 'stock'`），不是悬浮窗；退出用标题栏里的「返回家园」。
- 分页记忆写 `roco.homeView`；从蛋仓返回家园，账号胶囊、刷新、帮助都照常。

## 五、我的蛋仓（三态）

| 状态 | 布局 | 蛋卡列数（实测） |
| --- | --- | --- |
| 竖屏 390 | 标题 → 搜索 → 条件 → 蛋卡 | 4 列 |
| 横屏 844 · 展开 | 蛋卡 ｜ 筛选列 13rem ｜ 标题栏 2.6rem | 5 列 |
| 横屏 844 · 收起 | 蛋卡 ｜ 标题栏 2.6rem | 7 列 |
| 横屏 1120 · 展开 | 蛋卡 ｜ 筛选列 14rem ｜ 标题栏 | 8 列 |
| 横屏 1120 · 收起 | 蛋卡 ｜ 标题栏 | 11 列 |

- 蛋卡宽 `5.1rem`（≈77px），展开 / 收起**宽度不变**；列数来自 `grid-template-columns: repeat(auto-fill, 5.1rem)` + `justify-content: start`。
- 去掉卡片上方留白：横屏隐藏顶栏 + 页面 `padding-top: .35rem` + 卡片 `padding-top: .45rem`。
- 标题栏三项都是 `width: 2.6em; word-break: break-all` 的文本块，两字一行；收起后第三项由「收起筛选」变「展开筛选」，其余不动。
- 蛋仓数据与「组内广场 → 蛋仓」是同一份：进屏时按当前小组把本机采集的蛋补同步（`useEggStockSync` 水印增量），标注改完也同步回去。未登录 / 未入组时给「去登录」「去组内广场」出口。

## 六、我的 / 换蛋（2026-11-22）

两页照同一副骨架切，竖屏一行不改。

| 页 | 主区 | 功能列 | 纵向标题栏 |
| --- | --- | --- | --- |
| 我的 | 当前分区内容（小组 / 身份 / 数据） | 无 → 只两栏 | 小组 / 身份 / 数据；数据分区下再挂 导入 / 附近；返回小组并入标题栏；不画页名 |
| 换蛋 | 需求卡（固定 7.6rem，`auto-fill` 加列） | 搜索精灵名、去计划添加、只看我能接 | 我的收集 / 组内广场、蛋仓、我的换蛋、收起筛选；不画页名 |
| 换蛋 → 蛋仓 | 蛋卡（固定 5.1rem） | 搜索蛋名 + 标注条件 | 返回换蛋 / 我的蛋仓 / 收起筛选 |

- 「我的」没有搜索与条件，标题栏因此**没有折叠项**；分区导航就是标题栏里的两字文本项，当前项 `aria-pressed="true"`。
- 「我的」「换蛋」都不画页名；标题栏从第一项（分区 / 视角入口）直接开始，避免和左侧页签重复。
- 换蛋的两个视角（我的收集 / 组内广场）与两个页面入口（蛋仓 / 我的换蛋）都是页面级切换，全部进标题栏而不是功能列；收起筛选后仍然留在标题栏里，不用为了切入口重新展开。
- 标题栏顺序固定：视角（我的收集 / 组内广场）→ 页面入口（蛋仓 / 我的换蛋）→ 筛选开关；除最后一项外均为纯文本。数量用小号灰字挂在入口下面，不额外做角标。
- 换蛋页折叠键 `roco.swapRailCollapsed`，与蛋仓的 `roco.eggStockRailCollapsed` 分开记，互不影响。
- 换蛋页子页「蛋仓」复用同一个 `EggStockPanel`，只多传 `collapsibleFilterRail` 与 `railBack`；「返回换蛋」就在标题栏最上面。
- 换蛋页的需求卡横屏保持竖屏宽度（7.6rem ≈ 114px），只加列、不拉宽。
- 换蛋页「我的收集」不再写「想收」标题，需求卡直接从顶部铺；「组内需求」标题与条数仍留在主区顶部。
- 「去计划添加」放在搜索框右下方，不进标题栏；横屏在功能列、竖屏在主区，且只在「我的收集」视角出现。
- 蛋详情弹窗横屏走两栏：左「概览 + 关键数值」、右「实际父母」；数值网格横屏两列、竖屏三列，正文高度从 298px 压到 186px，390 高下一屏放下。时间保留完整值，长文本截断但保留 `title`。
- 实际父母直接用配窝精灵卡（`PairingPetCard`）：卡宽固定 `6.5rem`、`auto-fill` 排几列，不随左右栏宽拉伸；缺个体测量时只画蛋组 / 奖牌 / 性别 / 性格 / 名字 / 窝位，不补假数据。
- 压缩不等于删信息：父母推算说明（游戏未确认亲子关系）、学院 `100%性格`、配对过期提示都保留，只缩小字号或并入同一行。
- 「我的换蛋」（任务子页）仍是旧布局，见 §十一。

## 七、折叠交互

- 折叠开关只有一个按钮：`aria-expanded` 表达状态，`aria-label` 在「展开筛选 / 收起筛选」之间切换。
- 收起 = 功能列**整列消失**（不留窄条），省下的宽度全部给主区；标题栏不收起、不换位。
- 记忆键按页分开：`roco.eggStockRailCollapsed`（蛋仓）/ `roco.swapRailCollapsed`（换蛋），值 `1` / `0`；按设备存，不跟账号、不进云同步。
- 收起只加列、不放宽卡片；重新展开回到放宽前的列数。
- 没有功能列的页（我的）没有折叠项，标题栏只负责返回、标题与分区导航。

## 九、验收清单

1. 三个尺寸各截图：390（竖屏保持原样）、844、1120（横屏展开 + 收起各一张）。
2. 蛋卡宽展开 / 收起一致（77px）；列数 4、5→7、8→11；需求卡保持 7.6rem、只加列。
3. 顶栏与内容 `scrollWidth ≤ clientWidth`，无横向滚动。
4. 标题栏宽 ≈2.6rem（实测 39px），右缘与卡片留内边距（实测 13~15px），文字不被裁。
5. 收起后刷新页面仍是收起，`localStorage` 键值正确（蛋仓 / 换蛋各一个键）。
6. 竖屏不出现功能列 / 标题栏，标题与返回按钮回到页面顶部。
7. 我的：844 / 1120 只两栏，分区与数据子视图在标题栏；返回小组在标题栏最上面；标题栏不出现「我的」页名。
8. 换蛋：844 / 1120 展开 + 收起各一张；收起后主区变宽、需求卡不拉宽；蛋仓子页标题栏出现「返回换蛋」并能回主区；换蛋主区标题栏不出现「换蛋」页名。
10. `npx vitest run src/ui/plan src/ui/Home.test.tsx src/ui/Profile.test.tsx` 全绿；`npx tsc -b` 无报错；文案 lint 无新增。

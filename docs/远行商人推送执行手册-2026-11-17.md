# 远行商人推送执行手册

更新时间：2026-11-17

## 当前结论

远行商人推送由机器人插件 `RocomUID` 负责，与网页端、工具箱网页发版无关。

- 该群的「推送筛选」是空的，**空筛选 = 每轮商品全部推送**；

- 日志中没有任何一次成功执行「设置商人推送」的记录，即筛选从未被设置过。

## 使用前提

1. 机器人（GsCore / NoneBot / LLBot）在线，且仍在目标群内；
2. 插件配置里已填写 `RC_wegame_key`（wegame 后台 key）。key 为空时定时任务会直接退出，**不会推送任何内容**；
3. 推送开关按「群」或「QQ」单独保存：在群里发送开启命令，只对那个群生效；私聊发送，只对那个 QQ 生效。

## 命令一览

### 可用命令

| 作用 | 命令 | 说明 |
| --- | --- | --- |
| 开启推送 | `rc开启远行商人` | 群内发送=为这个群开启；私聊发送=为自己的 QQ 开启 |
| 关闭推送 | `rc关闭远行商人` | 只关当前群/当前 QQ 的推送 |
| 设置筛选 | `rc设置商人推送 国王球 炫彩蛋` | 多个商品名用空格或 `，、；/|+` 分隔；**不带任何商品名 = 清空筛选，恢复全推** |
| 查看筛选 | `rc查看商人推送` | 显示当前筛选匹配到了哪些商品 |
| 查今日四轮 | `rc今日远行商人` | 查看当天已记录的各轮商品，不重新请求接口 |
| 立即查本轮 | `rc远行商人` | 立即向接口拉一次当前轮商品；此命令**不受筛选限制**，总是返回整轮 |

### 帮助里印着、但实际不存在的命令

`rocom_help/help.json` 里有一条名为「远行商人推送」的条目，示例写的是 `[开启/关闭]远行商人`。

**机器人里并没有注册这个命令**：发送 `rc远行商人推送` 不会有任何回复（2026-11-16 09:00:13 有过一次真实发送，日志中只有「收到事件」，没有命令触发、没有回复）。请只使用上表里的命令，看到「远行商人推送」这条帮助请忽略。

## 设置筛选的步骤

1. 确认这个群/这个 QQ 已经开通过推送（发送过 `rc开启远行商人`）。没开通过时，设置筛选会提示「尚未开启远行商人推送」。
2. 发送 `rc设置商人推送 商品名1 商品名2`。
3. 机器人会回一条结果，列出「匹配到的商品」和「未匹配到：第N个」。
4. 用 `rc查看商人推送` 复核当前生效的筛选。

注意三点：

- 筛选是**按轮次生效**：这一轮里只要有任意一个目标商品，就会推送**整轮商品图**（图里仍会包含其他商品），不会只截出目标商品。
- 商品名对着游戏里的物品名写比较容易匹配；匹配规则比较宽松（包含关系、按顺序包含即可），写短一点更稳，例如 `国王球`、`炫彩蛋`、`首领血脉秘药`。
- 设置时如果提示「未匹配到商品，可能不会推送」，说明这个词不在机器人的可推送商品名单里，建议换一个更接近游戏内名称的写法。

## 查看与清空筛选

- 查看：`rc查看商人推送`。若回复「当前未设置远行商人推送筛选，每一轮商品都会推送」，说明筛选是空的。
- 清空：`rc设置商人推送`（后面不跟任何商品名）。回复「已清空远行商人推送筛选，之后每一轮商品都会推送」。

**空筛选等于全推，这是设计如此，不是故障。** 想让某一轮不刷群，只能设置筛选；没有「只关某一轮」的开关。

## 哪些情况会收不到推送

以下是 2026-11-17 已核实的真实情况：

1. **取数失败，整轮静默跳过**。接口拉取失败时只写日志（warning），不通知任何人，这一轮就没有消息。
2. **接口 429 / 未刷新时，实际只重试 1 次**。代码里读的 `RC_merchant_retry_count` 没有登记在配置项里，取到的是缺省值，换算后重试次数等于 1。真实案例：2026-11-16 12:00 因 `HTTP 429` 拉取失败，同一秒就判定「本轮跳过推送」，整轮没有消息。本来配置里的意图是每 30 秒重试、最多 20 次。
3. **筛选设置过、但本轮没有目标商品**，会跳过（日志会写「本轮远行商人没有该目标设置的商品，不推送」）。这是正常行为。
4. **没有开启推送**（没有订阅行），定时任务不会给任何人发。
5. **`RC_wegame_key` 为空**，定时任务直接退出，什么都不发。

判断方法：只要日志里出现「远行商人正在进行第1次数据获取」之后没有「跳过推送」的告警，就说明数据取到了；此时群里没有消息，优先怀疑筛选（`rc查看商人推送`）或订阅状态。

## 常见问题

### 每轮都在刷，想只看某几样

发送 `rc设置商人推送 商品名`。设置前的历史消息不会撤回，从下一轮开始生效。

### 设置了筛选，但那一轮本来有目标商品却没推

先用 `rc查看商人推送` 确认筛选还在、商品名对得上；再看日志有没有取数失败或 429。商品名与游戏内名称差异过大时会匹配不上。

### 群里被 `@全体` 了，能不能关

目前不能。代码里已经没有该开关，群推送固定 `@全体`。

### 只想自己看，不想刷群

群内开启和私聊开启是两条独立订阅。可以在群里 `rc关闭远行商人`，再私聊为自己的 QQ `rc开启远行商人`。

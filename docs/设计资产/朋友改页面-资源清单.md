# 朋友改页面：资源清单

分支：`codex/friend-ui-assets-20261117`  
基线：`release/prod-1.5.0 @ 88bce8d`  
用途：只做 HTML/CSS/原型调整，不接生产业务、不打包、不部署。

## 先从这里开始

1. 先读 [原型与外壳规范](原型与外壳规范.md) 和 [设计资产总览](README.md)。
2. 整页原型统一复用 [`docs/prototypes/shared/`](../prototypes/shared/)。不要复制一套新的工具箱标题栏、六个主入口或小组层级。
3. 改完用真实屏宽检查 375 和 390；需要新增页面或明显改版时，先产出可交互 HTML 或两张截图，再进入业务代码。
4. 改动 HTML 后运行 `node scripts/design-assets.mjs --write`，再运行 `node scripts/design-assets.mjs --check`。

## 正式资源和边界

- 正式 React 代码、`public/` 下资源、`latest.apk`、任何 `version.json` 不在本分支的页面整理范围内。
- 不要把 API Key、个人样本或运行时配置复制进原型。
- 朋友分支不部署正式站；页面确认后由主项目另行评审、合并和验收。

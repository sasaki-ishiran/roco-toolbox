# 换蛋任务长按排序：原型经验

日期：2026-11-16。范围：本地 HTML 原型，尚未接入 React 或生产。实现：`2026-11-15/换蛋撮合原型/shared/task-sort.js`。

## 用户体验约定

- 按下静止至少 300ms，再移动超过 8px 才排序；仅长按不移动不改变顺序。
- 300ms 前超过 8px 视为普通滑动，取消候选，不抢列表滚动。
- 排序时留浅色占位，副本随手指移动；靠近边缘自动滚动，松手提交。
- 按钮、输入框、链接与标签不发起排序；点击收货、上窝、催进度仍是普通操作。
- 取消触摸、多指、失焦或切后台恢复原顺序；拖完短暂抑制尾随点击，防止误收货。
- 顺序仅保存在本机 `roco.prototype.eggTradeOrder.v1`；桌面可用 Alt+上下方向键调整聚焦卡片。

## 实测问题与处理

1. Chrome 原生触摸有事件投递距离，CDP 移动 10px 可能尚未收到 touchmove。用真实触摸 24px 验证拖动，另用鼠标验证 7px 不触发、9px 触发；不把系统阈值写进产品规则。
2. 静态 `touch-action:none` 会损害普通滚动。本稿 touchstart 不拦截，仅进入排序后在非 passive 的 touchmove 中 preventDefault；上线前补 iOS Safari 实机验证。
3. 副本移除任务/操作标识，设置 inert、aria-hidden、pointer-events:none；否则顺序查询会把副本算成真任务。
4. 取消按原节点顺序还原，提交只回传任务 ID；React 落地由状态驱动排序，不照搬命令式 DOM 调整。
5. 生产组件卸载须清理全局监听和 RAF；当前 attach 仅在整个原型启动时调用一次，不能直接当可反复挂载的组件。

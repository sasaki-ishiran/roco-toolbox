# Android Collector Implementation Plan

> **For agentic workers:** Use executing-plans inline; user authorized the proposed integration. Track each deliverable with tests and a commit.

**Goal:** 在洛克工具箱 APK 内完成采集、保存、本地解析及导入，保留外部导入。
**Architecture:** 独立原生采集包 + 受限 JS 桥；磁盘文件流交给已有导入链路；PCAP 用 Worker 解码。
**Tech Stack:** Android Java 17 / SDK35 / NDK28.2.13676358 / CMake3.22.1，React18 / Vite5 / TypeScript。
**Spec:** ../specs/2026-10-24-安卓内置采集-design.md

## Global Constraints

- minSdk23 保留，采集 API26+；不改领域算法、同步键和 D1 schema。
- PCAP128MiB、最多10个文件、异常文件禁止一键导入，不能静默截断或删除。
- 只允许官方来源使用原生桥；不使用作者云端、令牌或升级通道。
- 停止后排空写队列；原始文件持久保留，导入明确触发。

## Review Focus

- 取消 VPN 授权回到可开始状态；用户不被永久 busy 锁住。
- 进程中断的文件可见但不能当正常抓包导入。
- 重复点导入或切页不重复消费；失败后同一文件可重试。
- 大文件不进入 Java byte[] 或 Base64；Worker 错误释放实例并保留文件。
- 老 APK、网页和 Android6/7 没有伪造可用采集按钮。

# 里程碑 2：我的精灵 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: 用 superpowers:subagent-driven-development（用户已选定）逐任务执行。步骤用复选框跟踪。

**Goal:** 做出「我的精灵」页：能按账号筛选、按标签叠加筛选、看到每只精灵的盒子位置，并能切换种公视角与母本视角。

**Architecture:** 沿用里程碑 1 的结构。领域层新增两个纯函数模块（数据规范化后的标签索引、筛选取交），不依赖 React 与浏览器 API；界面层新增标签栏、精灵卡片列表与页面导航；存储层的快照结构扩展盒子字段（旧快照缺字段时降级显示"未知"）。

**Tech Stack:** Vite + React 18 + TypeScript + Tailwind v3 + Vitest + Playwright（沿用）。

**Spec:** [2026-09-25-洛克工具箱-design.md](../specs/2026-09-25-洛克工具箱-design.md)（§7.1、§7.3 的母本部分）

## Global Constraints

- 移动优先，Android Chrome 为主；单手可操作，点击区不小于 44px。
- 无后端；账号数据只存手机本地 IndexedDB。
- 图鉴与账号数据的连接键是 `speciesPetId` ↔ `game_id`；**禁止**使用 `runtimePetId`。
- 母本计数单位 = `evolution_id`（形态级进化链）；蛋组 1（未发现）必须排除出可孵蛋统计。
- 分贝值与体型判定只能来自抓包数据；不提供手动录入与手动改判。
- 界面必须保留数据来源与 CC BY-SA 4.0 署名链接。
- 所有实现走 TDD：先写失败的测试，看到它失败，再写实现。
- 领域层纯函数不得 import React 或浏览器 API。

## Review Focus

1. 旧快照（里程碑 1 导入的、没有盒子字段的数据）在列表里不能崩，盒子位置显示为"未知"。
2. 标签叠加筛选的结果必须等于各标签集合的交集；任一标签命中 0 时列表给出空状态而不是白屏。
3. 账号筛选支持单选与多选；未选任何账号时不显示精灵（避免误解为"全部为空"）。
4. 一只双蛋组精灵在按蛋组筛选时，两个蛋组的标签都要能筛出它。
5. 精灵数量达到数千时列表仍可滚动（虚拟滚动或等效方案），首屏渲染不卡顿。

### Task 2: 标签索引与筛选引擎（纯函数）

**Files:**
- Create: `src/domain/petFilters.ts`
- Test: `src/domain/petFilters.test.ts`

**Interfaces:**

```ts
export type TagKind = 'account' | 'body' | 'voice' | 'gender' | 'shiny' | 'eggGroup' | 'nature';
export interface PetTag { id: string; kind: TagKind; label: string }
export interface BuildResult {
  tags: PetTag[];                        // 所有可选标签（含每种标签的命中数）
  tagCounts: Record<string, number>;     // 标签 id → 命中精灵数（不受当前筛选影响）
  index: Record<string, number[]>;       // 标签 id → 精灵在 owned 数组中的下标
}
export function buildTagIndex(
  owned: OwnedPet[],
  speciesByGameId: Map<number, SpeciesEntry>,
  eggGroupNames: Record<number, string>,
): BuildResult;

/** 叠加筛选：返回同时命中所有选中标签的精灵下标（selected 为空 → 空数组）。 */
export function filterByTags(index: BuildResult['index'], selectedTagIds: string[]): number[];
```

- [ ] **Step 1: 写失败的测试** —— 覆盖：账号标签、大块头、婉转声（96~100）、满分（100）、公/母、异色、蛋组（双蛋组精灵两个标签都能命中）、性格；`filterByTags` 的交集语义；`selected` 为空返回空数组；某标签命中数为 0 时该标签仍出现在 `tags` 里且 `tagCounts` 为 0。

## 领域规则落实

1. **后代物种/形态跟随母方**：`expected.species` 取母方物种名（含形态），不取父方；单测断言 `!== '种公兽'`。
2. **声音遗传 =（父+母）/2 向零取整**：`averageVoice` 用 `Math.trunc`；单测覆盖 `100+100=100`、`100+99=99`、`99+100=99`（不是四舍五入到 100）。
3. **双大块头 → 大块头后代**：`expected.body` 仅在父子母均为大块头时为「大块头」，否则标「不确定（需双大块头）」。
4. **性格由学院小窝 100% 遗传**：`expected.nature` 取目标性格，`reason` 明确写成「性格由学院小窝 100% 指定为『X』」，不写成配种遗传项。
5. **只推荐能真正产出满分大块头的组合**：父本与母本都必须满足「同目标蛋组 + 大块头 + 100dB」；母本额外要求 100dB。用普通母本或缺大块头满分公的单测都返回空数组。
6. **无可用配对**：返回 `[]`，并给出 `BREED_EMPTY_NOTE` 可读引导文案；界面在 `owned.length > 0` 且无配对时展示它。
7. 领域层为纯函数，未 import React 或浏览器 API。

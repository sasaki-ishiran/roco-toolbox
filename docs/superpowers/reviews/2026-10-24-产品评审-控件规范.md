# 全站交互与组件规范审阅

审阅日期：2026-10-24。基线：brief 指定的 ec55b22；本文按工作区当前源码核对，未修改产品代码、Git 或部署，未使用真实账号浏览线上产品。以下“现状”是源码与已有设计文档证据，“建议/验收”是待实施方案，不能视为已经观察到的用户行为或测量结果。

目标是让玩家容易回答“我收集到哪了、下一步做什么”。推荐保留当前 React + Tailwind、白卡片与翠绿主色，先统一搜索、筛选范围和反馈状态。当前问题主要是相同操作的规则不同、相似控件实际改变不同范围的数据；不需要先替换整套组件库。初始设计也明确“组件按需自建，暂不引入组件库”（`docs/superpowers/specs/2026-09-25-洛克工具箱-design.md:163`）。本次补充使用 react-best-practices 审阅原则和 breeding-planner 领域约束；具体母本口径以当前领域代码和较新共享规范为准。

已接受的约束：组主改组长、外部补齐改未收集、已有小组时创建/加入表单下移。这些由主任务处理，不算本文新发现。二期共同缺口/认领尚未实现，不能用未来界面替代当前行为。既有“账号默认展开”“筛选维度互斥展开、多选后不自动收起”有明确用户决策，本文保留，后续不因统一视觉擅自反转。

## 二、最小 UI 契约

### 1. 搜索：同一入口、可解释匹配

- 位置：当前对象清单顶部，独立于高级筛选；有清除文字按钮，可访问名“清除搜索”。结果说明紧跟其后，例如“我的母本 · 已选 2 个游戏账号 · 未收集 18 种”。
- 输入时即时本地筛选，不因网络轮询重置输入；键盘输入组合期间不触发跳转。只有明确访问远程服务才显示搜索加载，避免给本地 contains 匹配加无意义 spinner。
- 基础匹配沿用当前首尾去空格、大小写不敏感、子串匹配；不宣称支持拼音/首字母/模糊纠错。数字默认按图鉴号文本子串匹配；如另加 `#123`、全角/半角归一化，属于显式能力扩展，先加领域用例再改。暂不悄悄引入分词/多关键词 AND，避免既有输入语义变化。
- 对象契约如下。SearchField 只处理展示、清空、label、输入事件；索引与匹配留在领域函数/页面适配层。

| 对象 | 应匹配字段与关系 | 结果必须让人明白什么 |
|---|---|---|
| 拥有的精灵/种公/特殊精灵 | 现有进化链名称、形态显示名、图鉴号；未知物种保留抓包原名兜底 | 显示真实拥有个体的名称/游戏账号；必要时加“同进化链命中”，不能声称拥有搜索的另一形态 |
| 我的母本/小组母本资源 | 同一 eggGameId 所属全部形态名、蛋名对应显示名、图鉴号 | 结果单位为一种蛋血脉；保留来源个体/来源游戏账号详情；“搜火神命中火花”不表示多出一种母本 |
| 换蛋建议 | 当前保证性格、推荐显示名、蛋组；字段之间加明确边界以防拼接边缘误匹配 | 搜索只改推荐展示，不改目标计算；日后要支持同血脉搜索应增加独立验收，不默认为已经具备 |
| 成员/游戏账号 | 若选项量大再加局部搜索，仅限显示名和可显示标识 | 搜成员不改变本人身份；游戏账号重名用 UID 区分；恢复码/令牌不进入检索文本 |

搜索无结果时保留搜索和筛选，显示“没有符合当前条件的结果”，主恢复动作为“清除搜索”，次动作为“清除本页筛选”。只有确实没有导入数据才引导导入。只有目标全集与数据都完整、当前条件无未收集项时，才显示“这个范围已收集齐”。

### 2. 单选、多选与分段

| 控件 | 适用/交互 | 状态/无障碍契约 |
|---|---|---|
| InlineSelect | 四档母本浏览、成员筛选；页内展开，选一项立即收起，点外/Esc 收起并返焦；长列表限高、内部滚动。小屏优先容器内展开，只有确实放不下时再复用 sheet。 | 有 label、当前值、展开态。采用完整 button+listbox/option+aria-selected 和上下/Home/End/Enter 操作；不把选择动作误标成操作型 menu。不愿维护 listbox 时，可用弹层内原生 radio list，保留自然键盘语义。两种方案选一种，不混拼。 |
| MultiChoice（现有 FilterAccordion） | 同维度 OR、跨显示维度 AND；维度互斥展开；选项不自动关闭；每组可清除。 | 当前选中即便 count=0 也必须能取消。当前 MyPets 给所有 count=0 选项 disabled（`src/ui/MyPets.tsx:375`），实施时验证已选零结果项的解除路径。头部显示摘要/数量；清楚区分“未限制”与“目标已全取消”。 |
| SegmentedControl | 2–3 个互斥视图或状态，如 全部/种公/母本、已收集/未收集。多个独立维度不能塞进同一分段。 | 统一外观与 44px 触区。简单筛选用具名 group+aria-pressed；真正切面板才用 tabs，必须配 tabpanel、关联 id、roving tabindex/方向键。TabNav 若代表页面导航用 aria-current="page"，不为看起来像 tabs 而伪装完整 tablist。 |
| Checkbox/Toggle | “只看有人拥有”、是否参与筛选、共享选号；on/off 设置用 switch。 | 文案明确主语；整个 label 可点。共享选号属于发布草稿，点选不立即发布，不能和只影响显示的筛选做成同一无标题芯片条。 |

“空选择”的规则不能为了复用控件强行统一：普通标签与母本条件空维度为“不限”；账号全部取消为“未选游戏账号”；覆盖目标蛋组/档位/自选性格全取消为“未设置目标”。组件显式接收空选择说明，领域函数决定结果，不能用通用组件默认 `[] = 全部` 覆盖三类语义。

### 3. 范围与口径：每块结果能回答“谁的数据、什么标准、什么时候”

建议用轻量 ScopeSummary，一行主摘要、展开再看细节，不增加一层大型控制台。

| 范围 | 默认摘要示例 | 边界 |
|---|---|---|
| 本人本地收藏 | “我的收藏 · 2/3 个游戏账号” | 顶部账号筛选继续跨看板/精灵/覆盖/换蛋共享；改称“游戏账号”。仅一个账号时仍可用简短文字说明来源，不强制显示筛选控件。 |
| 种公计算目标 | “种公目标 · 追满分 · 大婉 · 14 蛋组” | 改档位/性格会改目标分母；不是普通展示过滤。现阶段保留看板唯一编辑入口，其他页面摘要给“调整目标”的导航，不复制一套编辑器。 |
| 我的母本条件 | “我的母本条件 · 大块头 · ±100dB” | 看板与个人母本页同源。蛋组搜索/显示筛选不改此条件；改变条件不等于新增实际收集事实。 |
| 小组资源 | “周末小组 · 已发布游戏账号 · 母/大块头/+100dB” | 与顶部私人账号筛选、本人条件独立；现有固定口径在二期前不允许编辑。摘要上写“小组条件”，不要把实现阶段“一期口径”作为主要产品词。 |
| 私有同步 | “工具箱身份已登录 · 私有数据上次同步…” | 登录识别同一个人；游戏账号是此人导入/明确共享的资源来源。云同步与小组发布分开显示成功，不把“同步成功”当“组员已看到”。 |

“未收集”必须伴随上下文。个人页表示在当前本人数据/条件下无达标母本；“小组未收集”只有全体成员摘要可比较且无人拥有才能确认；未发布、停止共享、口径/图鉴不匹配为“待确认”，列出人数和下一步。现有小组目录是全目标资源目录（`src/ui/MotherGroupResources.tsx:104`），不能仅换标题就当成共同缺口。二期认领代表“负责寻找”，与已拥有、已获得、已发布分开；导入+发布才更新拥有事实。以上遵循新讨论稿 `docs/superpowers/specs/2026-10-24-母本共享二期-讨论稿.md:19`、`:23`，并以较新用户措辞“组长/未收集”为准。

### 4. 状态：空、未知、失败、过时分开

| 状态 | 界面约定 | 不能做的推断 |
|---|---|---|
| 初次读取 | 同原布局的短加载提示/骨架，aria-busy；数据未读完不先闪“暂无数据” | 读取尚未完成 ≠ 从未导入/没有小组 |
| 从未导入 | 解释导入后立即得到的收集进度，主动作“导入游戏数据” | 无本地快照不阻断浏览已加入小组；现有 Swap 已支持，须保留 |
| 范围为空 | “未选择游戏账号/未设置目标”+原位置恢复入口 | 全不选 ≠ 数据丢失；不要让筛选控件随空列表消失 |
| 查询无命中 | 保留搜索与摘要，清除搜索/本页筛选 | 无结果 ≠ 已收集齐 |
| 个人缺口不可计算 | “先发布我的资源，才能计算我缺什么”或“资源需更新”；指向发布/更新 | 未发布 ≠ 已拥有全部，也不等于缺全部；避免同时出现普通零条空态 |
| 小组存在未知成员 | “已发布成员暂无；另 N 人待发布/更新” | 不写“全组没有”；不能进入已确认共同缺口口径 |
| 有缓存后刷新失败 | 保留上次成功内容；“暂时无法更新 · 上次获取 HH:mm”+重试 | 离线可浏览 ≠ 当前数据仍最新；不能把旧内容清成零 |
| 首次读取失败 | 可恢复错误卡+重试，不生成资源判断 | 无法获取 ≠ 无资源 |
| 数据过时 | 在决策结果旁显示源导出/上次导入时间，提供重新导入；保留已有一周规则作为提示 | 旧数据≠自动判无；小组刚刷新也不代表对方刚导出背包 |
| 本地导入成功/私有同步失败 | “已保存到本机；私有同步未完成”+重试 | 不让远端失败覆盖本地成功；不要笼统“导入失败” |
| 私有同步成功/小组资源未更新 | 各自独立状态；有变化时提示“更新共享资源后组员可见” | 同步成功 ≠ 已发布；现有发布预览与差异提示应保留（`src/ui/MotherResourceEditor.tsx:230`） |
| 操作成功/失败 | 成功 polite status；重要表单失败 alert，附可操作文案；错误关联输入，失败保留草稿 | 15 秒轮询不可每次朗读“已更新”；不能重复 toast 抢走注意力 |

网络状态和资源可比较状态用独立维度，不能合并成一个 success/empty 布尔值。UI 只消费判定结果；小组未知、共同缺口、达标判定由 domain/API 适配层给出。

### 5. 卡片、按钮、弹层与手机基础

- 卡片只定两档：一级内容 `rounded-2xl/p-4`，紧凑工具区 `rounded-xl/p-3`；嵌套详情用 slate-50 和轻分隔，不再一层卡片套一层同等阴影。摘要按“结果 → 条件/范围 → 一个下一步”排列。一个区域默认一个主动作；相邻筛选不是同等级主 CTA。
- 按钮只有 primary（翠绿实底）、secondary（边框）、quiet（文字）、danger（危险）四种角色。统一 loading/disabled/focus-visible。危险操作写对象，如“停止共享我的资源”“注销工具箱身份”；覆盖云端、撤回、解散等确认需写清影响。保留数据操作原有能力，放“更多/高级”后仍可找到。
- 排版维持现有清爽密度：主要正文 14px 左右、辅助正文 12px 左右；10/11px 只给版本等不影响决策的元信息。缺口、来源、状态不能仅靠极浅灰的小字传达。现有 slate-300/400 的具体对比度需要渲染检测后确认，不在源码审阅里声称已测合格/不合格。
- 触区至少 44px；输入和分段按同一基线对齐。长中文精灵/账号名应允许适当换行；截断的成员选项保留可读全名路径，不能只靠鼠标 title。320/360/390px 宽、200% 字体、软键盘弹起时都要能读到当前值和主要操作。
- 弹层共用 portal/层级规则：sticky 头部 < popover < 遮罩/dialog；同时只一个模态弹层。打开后聚焦标题/首个合适输入，Tab 限于弹层，关闭返焦原触发器；背景 inert、锁滚动；Esc/遮罩关闭只在无数据损失时允许，未保存发布草稿需明确退出规则。sheet 与底部按钮预留 safe-area，并用动态视口/内部滚动避免软键盘遮挡。
- 不新增全站多行 sticky 筛选墙；现在 header+TabNav 已 sticky（`src/App.tsx:120`）。先保持搜索与结果就近、每个折叠区自己可收起。确有长列表需要时才验证局部 sticky 的高度和锚点偏移。

## 三、持久化契约与渐进迁移

| 状态类型 | 建议生命周期 | 迁移方式 |
|---|---|---|
| 模式、种公目标、我的母本条件 | 长期；沿用当前已保存/同步行为 | 保留存储键与领域值；只统一编辑入口/摘要。私有同步覆盖了设置时继续清楚提示生效时点，不用新 UI 暗改同步优先级。 |
| 顶部游戏账号选择 | 沿用已批准的长期保存、跨页共享 | 不突然重置为全选；显示“2/3 已选”与全选；将筛选从显示名迁往稳定 accountKey 是独立数据迁移，先验证重名/改名，不在视觉重构里偷改。 |
| 本页普通筛选 | 同次使用跨页保留；已持久化的 MyPets 筛选先兼容 | 为每个视角设隔离键；旧值迁入相应视角并显示摘要。若未来改为只在会话保留，先告知并保留恢复路径，不能直接丢弃用户旧设置。 |
| 搜索词 | 同次使用跨页保留，刷新/重启默认清空 | 从组件局部态移到按视角命名的会话态；“全部”和“种公”分开。小组 query 按工具箱身份+groupId 隔离，不跨组借用旧成员条件。 |
| 主页面/换蛋-共享主视图 | 沿用当前跨重启保留 | 不为统一导航去掉“回来仍在小组”的现有保证（`src/ui/swapViewStore.ts:41`）。 |
| 小组内视图/成员/只看有人拥有 | 同次使用按身份+组隔离 | 成员离组后自动清非法选择；当前已有此处理（`src/ui/MotherGroupResources.tsx:56`），应保留。切身份立即清上一身份内存态。 |
| 页码/展开面板/下拉开关 | 轻量临时态；下拉关闭不保存 | 搜索/筛选变化回第一页；不要保留一个已无对应项的页码。切页后保留到何种程度逐页明示，统一组件不全局强制。 |
| 计划/认领/拥有事实/发布草稿 | 分别为持久意向、服务端协作任务、导入事实、未提交编辑 | 不复用一个 selected Set 表示多类事实；“清除筛选”绝不能清计划、已勾复制清单或发布草稿。草稿跨页保存需绑定组/身份，并始终标“尚未发布”。 |

## 四、最少需要提炼哪些组件

建议先做下列六组；复用现有代码，先迁移两个真实调用点再推广，不预先造复杂配置 DSL、不默认加库。

1. **SearchField**：label、输入/清空、辅助说明、结果数量关联、44px 高度、focus 样式。匹配索引、实体关系和查询结果不放进该组件。
2. **ChoiceControls**：统一 `SegmentedControl` 与 `InlineSelect` 外观/焦点基础；扩展现有 `FilterAccordion` 的摘要、空选择说明、可解除已选项。选择类型明确分开，不能一个 `Select` props 隐式猜单选/多选。
3. **FilterPanel + ScopeSummary**：清单搜索下的条件摘要、展开/收起、本页清除；用 slot 放“目标条件”或“显示筛选”，不由组件猜哪些值能重置。ScopeSummary 只展示传入主语/口径/时间。
4. **Button + Field**：四种动作层级、busy/disabled/focus、输入标签/错误关联。只集中复用样式与语义，不把导入、同步、发布三个 handler 合并。
5. **StateNotice / ResultState**：无数据、无匹配、不可计算、加载、离线缓存、错误、成功；标题/说明/动作由业务传入。保留 EmptyState 作为“未导入”的薄业务封装，逐步替换重复 JSX。
6. **ModalSurface / SheetSurface**：共用 portal、标题关联、焦点/关闭/滚动/安全区能力；CopySheet、GuideModal、ChangelogModal 保留各自内容与偏好逻辑。Card 容器的圆角/间距先用少量 token/样式函数即可，不必额外做几十种 Card 组件。

必须保持领域专属：CoverageMatrix 的格子/覆盖状态；MotherEggRow 的同蛋血脉和来源个体；共享资源预览的增/减/撤回；种公推荐与配窝可达性；私有合并同步冲突；二期认领的负责人/口径版本。它们可以使用通用 Button/Notice，不应被压成“通用列表卡片”导致关键信息丢失。不要通过改所有领域数据结构来实现视觉复用。

## 五、实施先后、替代方案与验收

**建议本轮先修语义与恢复能力，再逐步共用组件。**

- 第一批：修正范围误导文案、给母本条件/显示筛选分组；全部页搜索移出折叠；本页清除不清其他视角；不可计算不显示普通空态；统一“游戏账号/工具箱身份/私有同步/小组发布”的称谓。无需依赖二期 API。
- 第二批：SearchField、Button/Field、ChoiceControls，在搜索/下拉两个现存实现中验证；补选中态、label、键盘与 44px 触区。旧持久化设置保持兼容。
- 第三批：ModalSurface 与状态容器，补缓存获取时间和源数据时间；逐页迁移，保留现有自动导入与导入结果反馈。
- 二期前：以新的 ScopeSummary/ResultState 承载“我的未收集/小组未收集/待确认”；在 domain 输出已确认/未知后再增加任务认领。组口径可配置时继续与个人条件分开。

| 方案 | 成本/收益 | 判断 |
|---|---|---|
| 只改颜色/圆角、按钮尺寸 | 最快，保留全部行为分叉；可改善触摸但不能解决范围与空态误读 | 可作为小修的一部分，不足以支撑下一轮功能 |
| 当前结构内统一契约，按使用点迁移 | 涉及少数组件与状态边界，能保留专家功能/既有存储，容易逐步回退 | 推荐；先按上面批次落地 |
| 全站换库+重新搭页面 | 要重做紧凑交互、持久化、复制偏好、共享发布预览及无数据入口；验证面扩大 | 当前缺乏必要性；只有基础无障碍难以可靠维护时，再单独评估引入无样式的弹层/选择原语，而非全站换肤 |

以下是待实施验收任务与目标，不是已测结果：

1. 全部、种公、母本和换蛋列表都能在不展开高级筛选时搜索；输入后切其他主页面再返回，本次搜索仍在；清除搜索只清当前视角，不清长期目标/计划。
2. 全部页设置稀有度与种公页性格各一个条件；“清除本页筛选”只清当前视角。关闭/重开筛选不清值，应用重启保持原已批准的持久化行为，摘要准确。
3. 一只母本同时满足体型+声音才达标；同维度多选 OR，维度间 AND；空普通筛选=不限，空目标=未设置，空游戏账号=未选择。三个状态各有可恢复入口。
4. 查任一进化形态名/图鉴号能命中对应真实个体或同蛋血脉；明确区分不同 eggGameId；未知物种名兜底可查；换蛋只承诺实际支持字段。
5. 三成员中一人未发布/不兼容时，即使无人已知拥有也显示“待确认”；本人未发布时缺口不可计算；全员可比较且无人有才进入已确认小组未收集。导入成功/私有同步成功不自行改变小组发布事实。
6. 首读失败、缓存后断网、限流、源数据一周未更新、导入成功但私有同步失败分别有不同反馈；不以零项替代未知；重试保留搜索/草稿，不重复播报每次轮询。
7. 两个单选下拉均可键盘打开/导航/选择/Esc/返焦；多选点后仍展开且已选零计数项可取消。三个模态弹层背景不可交互，关闭返焦，复制 sheet 不落在 sticky header 之后。
8. 在 320/360/390px 宽和 200% 字体下检查：触区至少 44px、长账号/母本名可读、无页面横向溢出、软键盘不遮住关键提交动作、安全区有余量。用真实浏览器分别验证，而非将本报告源码分析视为视觉验收。

本报告只完成审阅与规范建议。未执行 UI 自动化、视觉对比或真实账号操作，未声称完成上述改造。后续每批实现应按项目工作流先写失败用例，再验证有意义的跨视角、口径边界和移动端交互；不为纯样式逐行镜像写测试。

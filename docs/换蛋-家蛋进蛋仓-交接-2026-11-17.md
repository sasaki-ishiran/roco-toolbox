## 二、现象

某账号家园里有 2 颗蛋（还在地上，没有收进背包）。用家园页面采集、以及在群里发 `rc生蛋了吗`，都没有让这 2 颗蛋出现在蛋仓，也没有完成自动标注。

## 三、已确认的事实

1. 蛋仓同步入口只吃背包：
   - `src/ui/plan/EggMatchingHub.tsx` L63-68：只 `inventoryFromSnapshot(snapshot)` 然后发 `stock-sync`。
   - `src/domain/eggInventory.ts` 的 `inventoryFromSnapshot` 只读 `snapshot.eggs`。
2. 家蛋数据字段不足：`src/domain/parseBackup.ts` L188-196 → `home.sceneEggs` 只有 `actorId / furnitureGuid / npcConfigId`，没有物种、蛋重、性格、声音、体型。
3. 家园刷新只并 home：`src/ui/homeRefresh.ts` L10-12、L28-49，注释明确"短采集不能整包替换"。
4. 蛋详情写死：`src/ui/plan/EggStockPanel.tsx` L48「暂无亲本记录」。
5. 领域模型是齐的但没接线：`src/ui/plan/eggStockModel.ts` L7-17（`location: 'bag' | 'home'`、`lastConfirmedAt`）、L42-84 `reconcileEggStock()`（home 先合并、bag 覆盖、complete 才删）。但在 `codex/egg-web-20261116`、`codex/egg-reminder-20261117`、`release/prod-1.5.0` 三个分支上 `git grep reconcileEggStock`，除 `eggStockModel.ts` 与 `eggStockModel.test.ts` 外零引用——线上是死代码。

## 四、另一条链路（已实现、已部署，不要改）

家园巡查 + QQ「已产出」提醒是独立链路，**不经过蛋仓**：

- 上游固定为 `https://wegame.shallow.ink/api/v1/games/rocom/ingame/`，查 `home/scene-info?uid=<UID>&wait_ms=0`，读 `data.home_scene_info`。
- 必须 `snapshot_status === 'valid'` 且 `egg_count === eggs.length`，否则整份场景丢弃。
- 每颗蛋读 `actor_id`、`nest_furniture_guid`、`mother_candidate{pet_gid,nest}`、`father_candidates[]`、`biological_parentage_confirmed`。
- 与上一次快照的 `actorId` 集合做差集，只处理新出现的蛋；首次查询只存基线、不提醒。
- 亲本匹配：母本 `pet_gid` == 任务里的 `capture_<uid>_<petId>` 且母本窝 == 蛋窝；父本 == 任务父本且父本窝 != 蛋窝；匹配到多个任务或多个父本记 `ambiguous`、不提醒。
- 只有「交易状态 accepted、且对应一侧还缺蛋 ID」的任务所在 uid 会被查，且小组机器人 `enabled=1`。
- 北京时间 8 点后运行，单 uid 30 分钟一次，每 tick 最多 3 个 uid，每天 100 次上游配额；`ROCOM_PATROL_API_KEY` 未配置时静默跳过。
- 代码位置：`functions/_lib/eggPatrol.ts`、`functions/_lib/eggPatrolStore.ts`、`functions/_lib/eggBotBridge.ts`、`src/shared/eggPatrol.ts`；插件侧 `D:\QQBot\gsuid_core\gsuid_core\plugins\RocomUID\RocomUID\rocom_toolbox\`。
- `rc生蛋了吗` 是纯查询（`rocom_homeinfo\__init__.py` L213-240、`egg.py` L24-56），只读上游并格式化文本，不写库，跨端也影响不到浏览器本地蛋仓。

# 手机怎么用（局域网版）

> **现在更推荐直接访问线上版 `https://roco-toolbox.pages.dev/`，或用配套的采集器 APK**（装好就是应用，
> 断网也能开）。下面这套「电脑起服务 + 手机连同一个 Wi-Fi」的方式仍然可用，适合本地调试或没有网络时。

## 一、电脑上启动服务

双击 **`启动手机版.cmd`**（在 `D:\desk\洛克工具箱` 下）。

它会先构建一次应用，然后列出手机可以访问的地址，例如：

```
   http://192.168.1.2:4173
   http://172.19.83.237:4173
```

**这个黑窗口要一直开着**（关掉就等于关服务器）。按 `Ctrl+C` 停止。

## 二、手机上打开

1. 手机连**同一个 Wi-Fi**（和电脑同一个路由器/同一网段）。
2. 用 Chrome 打开上面列出的地址，通常选 `192.168.x.x` 那一条。
3. 打开后是五个页签：看板 / 我的精灵 / 覆盖度 / 换什么 / 导入数据。

> 如果打不开：① 确认电脑那个窗口还在运行；② 确认手机连的是同一个 Wi-Fi（不是流量）；③ 第一次运行时 Windows 防火墙会弹窗问是否允许 Node.js，必须点「允许」（专用/公用网络都允许最省事）。

## 三、把数据导进手机（必须做一次）

**手机上的数据是独立的**，电脑上导入过的不会自动同步过来，需要在手机上重新导入一次：

1. 用**采集器 APK** 在手机上抓一次包（抓完在游戏里「分享给洛克工具箱」），或把已有的
   `.json` / `.pcap` 文件传到手机（微信「文件传输助手」、QQ 传给自己、或数据线拷贝都行）。
2. 手机打开应用 → 「**导入数据**」页 → 点「**导入游戏数据**」→ 选中那 4 个文件（可以一次多选）；
   如果走的是「分享给洛克工具箱」，数据会自己进来，不用手选。
3. 导入完成后看板应显示：种公网络「已通 N / 14 组」与「母本全收集」两块进度卡。

> 数据存在**手机浏览器本地**：换浏览器、清理浏览器数据、或用无痕模式都会丢。所以别清理这个网址的站点数据。

## 四、手机上能做什么

| 页签     | 用途                                                                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 看板     | 当前模式开关（追满分 / 追双牌 + 目标档位）+ 两块进度卡 + 优质种公推荐 + 配窝建议（含小窝摆位图）                                             |
| 我的精灵 | 按账号、大块头、婉转声、满分、公母等标签筛选；可切种公视角（档位 / 性格 / 蛋组筛选）、母本视角（待补齐母本可搜索、勾选形成「计划收集」待办） |
| 覆盖度   | 每个蛋组的通 / 未通与性格明细；展开能看到**是哪只种公（账号 + 盒子位置）**、该把哪只放进学院小窝、普通小窝配哪只。性格筛选在组内             |
| 换什么   | 换蛋目标清单：一条 = 性格 + 精灵名（官方名），可勾选多条一次复制去交易；复制格式为「（绿窝/普通窝）+档位」+ 每行「性格+名字」                |
| 导入数据 | 主按钮「导入游戏数据」（采集器里分享过来会自动进来，也可以手选文件）；云同步（跨设备）；导入历史；底部「更多」里收着 导出全部数据 / 合并导入 / 重置；匿名统计开关 |

## 五、当前限制（知道就好，不影响用）

1. **上游数据更新（游戏版本更新）仍需在电脑上做**：双击 `刷新数据.cmd`，然后重启 `启动手机版.cmd`。手机内一键刷新属于里程碑 4，暂时没做。
2. **HTTP 下不能离线**：「添加到主屏幕」只是快捷方式，断网打不开。要离线得部署到 HTTPS（里程碑 4）。
3. 电脑关机或退出那个黑窗口，手机就打不开页面——但**已经导入的数据不会丢**，下次打开还在。
4. 手机和电脑各自一份数据，**不会自动同步**——要看两边全部账号，用下面第「六」节的合并导入。

## 六、两台设备怎么同步（手机 ↔ 平板 ↔ 电脑）

数据只存在各自设备上，所以靠**导出 + 合并导入**，一次就对齐：

> 两台设备都已登录同一个「云同步」账号时，直接在新设备上输恢复码一键拉取即可（见应用内「导入数据」页
> 的「云同步」面板），不用手动导出。下面是没开云同步时的做法。

1. **A 设备**：「导入数据」页 → **导出全部数据**（得到一个 `洛克工具箱备份-日期.json`）
2. 把这个文件发到 **B 设备**（微信「文件传输助手」、QQ、数据线都行）
3. **B 设备**：「合并导入」选这个文件。规则是——
   - B 设备**自己独有的账号照样保留**（不会被清掉）
   - 两边都有的账号**取导入时间较新的那份**
4. **反方向再做一次**（B 导出 → A 合并导入），两边就完全一致了

> 导出的文件包含**全部账号**，所以双方各导入一次就够，不用来回多轮。

**微信/QQ 收到备份时更省事**：直接点开那个 json → 「用其他应用打开 / 分享」→ 选「洛克工具箱」，
它会自动按合并导入处理（不用去应用里找文件）。
（「用其他应用打开」这条要 **1.1.3 及以上**的 APK；更早的壳只在系统分享面板里出现，这条列表里没有它。）

> 想做「整体覆盖」的还原：先点「重置导入数据」清空，再合并导入——结果就等于原来那份。

## 七、如果以后想彻底不用电脑

需要做里程碑 4 的两件事：① 把应用部署到免费 HTTPS 托管（手机可装成应用、可离线）；
② 把上游刷新做进应用里（手机点一下就能更新图鉴）。这两件一起做才有意义。

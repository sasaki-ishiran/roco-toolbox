# 补充数据投放区

把你看手上的资料直接丢进这个文件夹就行，格式不限，我先判断能不能解析。

## 放什么

1. **最新的精灵数据** —— 尤其是现有 wiki 数据里没有的字段，例如声音（高亢 / 低沉，或 -100～100 的数值）、体型阈值、性格、蛋组修正等。
2. **你账号已有的精灵清单** —— 用来初始化工具箱的「我的资源池」，不用你再手敲一遍。
3. **如果你有的话** —— 蛋重 / 声音的判定规则说明、截图、攻略贴原文，能帮助我校对字段含义。

## 支持的格式

表格（`.xlsx` `.xls` `.csv` `.tsv`）、文本与结构化数据（`.json` `.txt` `.xml` `.sqlite` `.db`）、游戏或第三方工具导出的存档、以及截图（`.png` `.jpg`）。都没问题就先丢进来，我逐一试解析。

## 隐私提醒

如果文件里带账号 ID、手机号、邮箱、UID 这类信息，能先去就去掉；不方便的话直接放，我会把这类字段标记出来、不入库，也不会出现在任何输出文件里。

## 我会做什么

先用只读方式识别格式和字段，给你一份「能认出来的字段 + 含义推测 + 缺失项」清单，确认字段含义之后再合并进 `data/pets.json` 和资源池。你给的数据和上游 wiki 数据分开放：上游快照在 `data/raw/`，你提供的原始文件留在这个文件夹，互不覆盖。

放好之后告诉我一声（或直接说「放好了」），我就开始解析。

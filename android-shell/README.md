# 洛克工具箱 Android 壳与本机采集

网页界面仍来自 `https://roco-toolbox.pages.dev/`。1.2.0 增加本机采集桥，必须配套部署包含 `NativeCollectorPanel` 的网页才能显示入口；旧网页、旧 APK 继续支持原来的分享与文件导入。1.2.2 增加「上传蛋神助手」：在文件列表点一次，就把原包直接送到蛋神助手云端采集接口，不再需要导出后转给原版采集器。

使用：我的 → 游戏数据 → 本机采集。完全退出游戏和其他 VPN/加速器后开始采集，同意系统授权，再打开游戏重新登录，依次查看精灵仓库、背包与蛋仓。回工具箱停止保存，然后按需点「解析并导入」或「上传蛋神助手」。是否收齐以实际返回数据为准，工具箱不自动声明完整。

- 原包在应用私有 `files/captures/`，最多 10 个、单个上限 128MiB；导入与上传都不删除原包。
- 正常停止会排空队列、flush/fsync/close 后才移除 `.incomplete`。异常中断、队列丢包或超限的文件保留，可导出、确认删除，禁止一键导入。
- 上传沿用蛋神助手公开 Android 采集客户端 1.2.6 的 V3 协议：原始 PCAP、5 MiB 上限、任务编号持久化，网络中断时只查询已有任务而不重复 POST。上传身份、版本号与发布凭据属于原版公开客户端，构建时从本机 `local.properties` 的 `capture.token` 注入，不写入源码或仓库；未配置时上传入口会明确报错，其余功能不受影响。
- 采集桥使用 AndroidX WebMessageListener，仅接受官方来源的主页面消息。系统 WebView 需支持 `WEB_MESSAGE_LISTENER` 和 `DOCUMENT_START_SCRIPT`；不支持时隐藏采集入口，更新系统 WebView 后可用，手动文件导入不依赖该桥。
- 新版原包通过随机授权 URL 交给 Web Worker 读取解析，Java 与主页面不保留整文件字节数组。
- 卸载应用会删除其本机数据；更新应使用同包名、同签名且更高 versionCode 的覆盖安装。构建验收记录会核对签名。

构建及组件许可见 [THIRD_PARTY.md](THIRD_PARTY.md)。真机验收需要检查系统授权取消、通知栏停止、实际登录与数据导入、上传入库结果、VPN 撤销、切后台和连续启动停止；桌面浏览器模拟桥不能代替这些检查。

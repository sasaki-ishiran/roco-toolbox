## 可验证的交互
- 我的收集 → 我的需求 → 组内供给 → 供给详情 → 选择自己库存蛋提出换蛋。
- 提出后需通过原型外部的“对方已接受”场景模拟远端事件，才出现需求方“已收到”；不会发起后直接假装成交。
- 组内广场 → 组员需求 → 我能提供，返回仍是组内广场。
- 同一种蛋合并多个目标性格；单颗已确认库存只显示其对应性格。
- 蛋仓 → 四列现蛋 → 蛋详情弹窗 → 挂出 / 暂停；自孵独立筛选，外部获得不可组内再流通。
- 我的换蛋卡内显示双方蛋、进度与操作；需求方“已收到”完成，供给方无第二次收货确认；300ms 后位移>8px 排序。
- 演示状态还包含空态、读取失败、供给方视角、多单内嵌分配。

## 本轮交互评审清单

常驻文档，不依赖聊天折叠区。

| 场景 | 用户能看到 / 能做什么 |
| --- | --- |
| 我的收集 / 组内广场 | 三列精灵卡、真实奖牌；需求分别归我和组员，不混角色 |
| 蛋仓 | 背包+家园未收蛋，四列蛋图；无已失效，不混入产线 |
| 自孵限制 | 独立来源筛选；外部或来源不明不可挂出，换回的蛋记外部 |
| 接单详情 | 弹窗保留来源，现蛋在上、可现孵在下；紧凑亲本卡 |
| 发布 / 调整 | 三列原发需求卡，每蛋多性格/更多性格/数量，不指定性别 |
| 撤回 | 未被接受可改撤；已被接受不显示改撤按钮 |
| 我的换蛋 | 卡内双方/进度/右下操作/催进度；长按排序、返回和刷新保留顺序 |
| 蛋详情 | 弹窗显示来源、位置、蛋组和有记录的父母；未知不补造 |

现蛋和现孵发起都进入换蛋列表；顶部“对方已接受”模拟远端事件。库存、父母、自孵来源均为本地示例。快照合并要求同周期完整背包+家园列表，局部采集不能据此删除库存。
